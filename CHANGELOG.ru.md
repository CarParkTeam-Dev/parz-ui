# Что нового

[English](CHANGELOG.md) · [Հայերեն](CHANGELOG.hy.md) · **Русский**

Все заметные изменения Parz UI. Номера версий идут по [семантическому версионированию](https://semver.org/lang/ru/): **patch** — исправления, **minor** — новые компоненты и настройки, **major** — изменения, после которых старый код может перестать работать.

Обновиться в своём проекте:

```bash
npm update @carparkteam/parz-ui
```

## Unreleased

## 1.0.1 — 2026-11-11

### Добавлено
- Страница «Что нового» на сайте — этот список изменений на трёх языках.
- Номер текущей версии показан рядом с командой установки на главной.
- `CHANGELOG.md` теперь идёт вместе с пакетом.
- Страница «Что нового» проверяет обновления: сравнивает версию сайта с последним выпуском (из `latest.json` на нашем сервере, а если он недоступен — из npm). Без интернета проверка просто не показывается.
- `npm run build` теперь кладёт рядом с сайтом `latest.json` с версией и датой.

### Исправлено
- **Parz Menu:** на iPhone (Safari) и некоторых Android-браузерах экран больше не приближается при нажатии на поле поиска — на сенсорных экранах текст в поле теперь 16 px.

## 1.0.0 — 2026-11-11

Первый публичный выпуск в npm под именем `@carparkteam/parz-ui`.

### Добавлено
- **Parz Menu** (`ParzMenu`) — навигация, где подсветка перетекает каплей; на компьютере становится шапкой с поиском.
- **Parz Toggle** (`ParzToggle`) — переключатель с жидким бегунком, его можно тянуть; есть состояние отказа «слишком часто» (`cooldown`, `canChange`, `onReject`).
- **Parz Checkbox** (`ParzCheckbox`) — цвет растекается каплей, галочка дорисовывается; «частично выбрано» и ошибка.
- **Parz Slider** (`ParzSlider`) — бегунок тянется по скорости движения.
- **Parz Range** (`ParzRange`) — от 2 до 5 бегунков на одной дорожке, `minDistance`, `fill="pairs"`.
- **AnimoLogo** — живой логотип-надпись.
- **ParzCredit** — готовая подпись «Components by CarPark Team», которую требует лицензия.
- Сайт с живым редактором и документацией для каждого компонента на английском, русском и армянском.
