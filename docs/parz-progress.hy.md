# Parz Progress

`ParzProgress`-ը Parz UI-ի առաջընթացի ցուցիչ է՝ գոտի կամ օղակ։ Երբ արժեքը փոխվում է, լցումը մեղմ զսպանակով սահուն հոսում է դեպի այն, այլ ոչ թե ցատկում։ Ոչինչ կտրուկ չէ։

- **արժեքի փոփոխություն** — լցումը և տոկոսները սահուն հոսում են դեպի նոր արժեքը;
- **փայլք** — գոտու լցման վրայով դանդաղ հոսում է մեղմ փայլք;
- **անհայտ տևողություն** — առանց `value`-ի (կամ `indeterminate`-ով) գոտու վրայով հեղուկ կաթիլ է հոսում, իսկ օղակի աղեղը շնչում և պտտվում է;
- **100%** — ուղին մեկ անգամ մեղմ փայլում է (`celebrate`);
- **քիչ շարժում** — `prefers-reduced-motion`-ի դեպքում արժեքը ցույց է տրվում միանգամից, իսկ անհայտ ռեժիմը պարզապես թարթում է։

Կոմպոնենտն ունի `role="progressbar"` և `aria-valuenow`, ուստի էկրանի ընթերցիչները հայտարարում են առաջընթացը։

```tsx
import { ParzProgress } from '@carparkteam/parz-ui';
import '@carparkteam/parz-ui/style.css';

<ParzProgress value={progress} label="Բեռնում" />

<ParzProgress variant="ring" value={progress} size="lg" />

// անհայտ տևողություն
<ParzProgress indeterminate label="Սպասեք…" />
```

| Prop | Լռելյայն | Ինչ է անում |
|---|---|---|
| `value` | — | Ընթացիկ արժեք։ Առանց դրա՝ անհայտ տևողության ռեժիմ |
| `max` | `100` | Առավելագույն |
| `indeterminate` | `false` | Անհայտ տևողություն՝ գոտու վրայով կաթիլ է հոսում, օղակի աղեղը պտտվում է |
| `variant` | `'bar'` | `'bar'` (գոտի) կամ `'ring'` (օղակ) |
| `size` | `'md'` | Գոտու բարձրություն `'sm'` (4 px), `'md'` (8 px), `'lg'` (12 px); օղակ՝ `28`, `44`, `68` px |
| `label` | — | Պիտակ գոտուց վեր; օղակի կողքին կամ տակ |
| `labelPosition` | `'end'` | Միայն օղակի համար՝ `'end'` — աջից, `'start'` — ձախից, `'bottom'` — օղակի տակ |
| `showValue` | `true`, եթե կա `value` | Ցույց տալ արժեքը՝ պիտակից աջ կամ օղակի կենտրոնում (`sm` օղակի դեպքում՝ ոչ) |
| `formatValue` | տոկոսներ | `(value, max) => ReactNode` |
| `status` | `'default'` | `'success'` — հաջողություն, `'warning'` — ուշադրություն (լցումը հանգիստ շնչում է), `'error'` — սխալ (մեկ մեղմ ցնցում), `'paused'` — դադար (գույնը խամրած է, շարժումը կանգ է առնում)։ Հաջողության, սխալի և դադարի դեպքում թվի փոխարեն պատկերակ է՝ նշան, `!`, դադար |
| `successMorph` | `false` | **Բետա։** 100%-ի և `status="success"`-ի դեպքում գոտին ձգվում է կաթիլի և դառնում շրջան՝ նշանով; օղակը լցվում է գույնով՝ նշանով։ Հետ՝ նույնքան սահուն |
| `celebrate` | `true` | Մեղմ փայլ, երբ հասնում է վերջին |
| `accent` | `#6ee7a0` | Լցման գույն |
| `trackColor` | կիսաթափանցիկ մոխրագույն | Ուղու գույն |
| `ariaLabel` | — | Անուն էկրանի ընթերցիչների համար, եթե `label` չկա |
| `className` / `style` | — | Արմատային տարրի վրա |

## CSS փոփոխականներ

`--pz-pg-accent` (լցում), `--pz-pg-success`, `--pz-pg-warning`, `--pz-pg-error`, `--pz-pg-paused` (վիճակների գույներ), `--pz-pg-track` (ուղի), `--pz-pg-h` (գոտու բարձրություն)։

```css
.uploads { --pz-pg-accent: #7aa7ff; --pz-pg-h: 6px; }
```
