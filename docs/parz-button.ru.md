# Parz Button

`ParzButton` — кнопка Parz UI с жидкой анимацией. При нажатии она мягко поджимается и пружинит обратно, а из точки касания растекается капля. Ничего не дёргается.

- **нажатие** — кнопка мягко уменьшается и пружинит, когда её отпускают;
- **капля** — волна растекается из точки касания (с клавиатуры — из центра);
- **удержание** — кнопка остаётся поджатой, капля дорастает, под подписью медленно течёт градиент; отпустили — всё плавно тает;
- **смена содержимого** — когда меняется подпись или иконка, старая растворяется, новая проявляется, а ширина перетекает к новой;
- **загрузка** — подпись плавно уходит, вместо неё «живые» точки, ширина не меняется; ставится `aria-busy`;
- **наведение** — меняется только цвет, кнопка не подпрыгивает;
- **клавиатура** — Tab для фокуса (видно кольцо), Enter или Пробел — нажать;
- **меньше движения** — при `prefers-reduced-motion` нет поджатия и капли, точки просто мерцают.

Внутри настоящий `<button>`, а при `href` — ссылка `<a>`, поэтому формы, ссылки и экранные дикторы работают как обычно.

```tsx
import { ParzButton } from '@carparkteam/parz-ui';
import '@carparkteam/parz-ui/style.css';

<ParzButton onClick={save} iconEnd="ms:arrow_forward">Продолжить</ParzButton>

<ParzButton variant="soft" loading={saving} loadingText="Сохраняем">Сохранить</ParzButton>

<ParzButton variant="glass" icon="ms:favorite" iconOnly ariaLabel="В избранное" />

<ParzButton variant="outline" href="/docs">Документация</ParzButton>
```

| Пропс | По умолчанию | Что делает |
|---|---|---|
| `children` | — | Подпись |
| `variant` | `'solid'` | `'solid'`, `'soft'`, `'outline'`, `'ghost'` или `'glass'` |
| `size` | `'md'` | `'sm'` (34 px), `'md'` (42 px), `'lg'` (52 px) |
| `shape` | `'pill'` | `'pill'`, `'rounded'` или `'square'` |
| `icon` / `iconEnd` | — | Иконка до / после подписи: встроенная, `'ms:имя'`, `'mi:имя'` или свой узел |
| `iconOnly` | `false` | Квадратная кнопка только с иконкой. Задайте и `ariaLabel` |
| `ariaLabel` | — | Название для экранных дикторов |
| `loading` | `false` | Вместо подписи живые точки; нажать нельзя |
| `loadingText` | — | Текст рядом с точками во время загрузки |
| `disabled` | `false` | Приглушена, нажать нельзя |
| `fullWidth` | `false` | На всю ширину |
| `href` / `target` / `rel` | — | Рендерит ссылку `<a>` |
| `type` | `'button'` | `type` у `<button>` |
| `onClick` | — | Обработчик нажатия; не вызывается при `disabled` и `loading` |
| `onLongPress` | — | Нажатие с удержанием: пока держат, под подписью течёт градиент; когда капля наполнит кнопку, вызывается это вместо `onClick` |
| `longPressDelay` | `600` | Сколько держать для `onLongPress`, мс |
| `accent` | `#6ee7a0` | Основной цвет |
| `textColor` | — | Цвет текста и иконок |
| `ripple` | `true` | Капля из точки нажатия |
| `id` / `name` / `value` | — | Передаются элементу |
| `className` / `style` | — | На корневой элемент |

## CSS-переменные

Задаются на кнопке или любом родителе: `--pz-btn-accent` (основной цвет), `--pz-btn-fg` (цвет текста), `--ltb-icon` (размер иконки), `--pz-btn-shade` — насколько затемнить текст у `soft`, `outline` и `ghost` (по умолчанию `0%`; на светлой странице ставьте около `45%`, чтобы светлый акцент читался).

```css
.checkout { --pz-btn-accent: #ff8a3d; }
.light-page { --pz-btn-shade: 45%; }
```
