# Parz Ruler

`ParzRuler`-ը նշագծերով սանդղակ է անշարժ ցուցիչի տակ։ Այն քաշում են մատով կամ մկնիկով. նետելուց հետո սանդղակը շարժվում է իներցիայով և զսպանակով կանգնում մոտակա նշագծի վրա։ Սանդղակի վերևում թիվն է՝ `ParzNumberFlow`-ով, որի թվանշանները թերթվում են մշուշով։ Ցուցիչի մոտ նշագծերն ավելի պայծառ են, իսկ եզրերին սանդղակը մարում է։

- **արժեքներ**. `min`, `max`, `step`՝ մեկ նշագիծ յուրաքանչյուր քայլին; `formatValue`՝ ինչպես ցույց տալ արժեքը (օր.՝ րոպեներ → `'08:30'`);
- **կառավարում**. քաշում իներցիայով, անիվ և թաչփադ, սեղմում նշագծի վրա; եզրից այն կողմ սանդղակը ձգվում է դիմադրությամբ;
- **ստեղնաշար**. սլաքներ՝ մեկ քայլ (Shift-ով՝ 10), PageUp / PageDown՝ սանդղակի տասներորդ մասը, Home / End՝ եզր;
- **տեսք**. `tickGap`՝ նշագծերի միջև հեռավորությունը, `majorEvery`՝ յուրաքանչյուր N-րդ նշագիծը երկար է, `accent`՝ ցուցիչի գույնը, `theme`;
- **ցուցիչը** արագության դեպքում մի փոքր լայնանում է կաթիլի պես;
- **ParzProvider**. զսպանակը հետևում է `calm` / `bouncy` / `snappy` նախադրվածքին;
- **քիչ շարժում**. `prefers-reduced-motion`-ի դեպքում սանդղակն անմիջապես կանգնում է տեղում;
- **ձև**. `name`՝ արժեքը կուղարկվի ձևի հետ;
- **բացառություններ**. `exclude`՝ սանդղակը բաց է թողնում այդ արժեքները և կանգնում մոտակա թույլատրվածի վրա;
- **տեքստ**. `labels={['Ani', 'Mark', …]}`՝ յուրաքանչյուր երկար նշագիծ մի անուն է, միջևում՝ կարճեր (`minorTicks`), վերևում՝ անունը։

```tsx
import { useState } from 'react';
import { ParzProvider, ParzRuler } from '@carparkteam/parz-ui';
import '@carparkteam/parz-ui/style.css';

const hhmm = (m: number) => `${String(m / 60 | 0).padStart(2, '0')}:${String(m % 60).padStart(2, '0')}`;
const [minutes, setMinutes] = useState(430);

<ParzProvider motion="bouncy">
  <ParzRuler value={minutes} onChange={setMinutes} min={0} max={1430} step={10} formatValue={hhmm} ariaLabel="Ժամ" />
</ParzProvider>
```

| Հատկություն | Լռելյայն | Ինչ է անում |
|---|---|---|
| `value` | — | Արժեք (կառավարվող ռեժիմ) |
| `defaultValue` | `min` | Սկզբնական արժեք (չկառավարվող ռեժիմ) |
| `onChange` | — | Յուրաքանչյուր նոր արժեք, նաև երբ սանդղակը շարժվում է |
| `onChangeEnd` | — | Երբ սանդղակը կանգնել է |
| `min`, `max`, `step` | `0`, `100`, `1` | Սահմաններ և քայլ |
| `tickGap` | `16` | Նշագծերի միջև հեռավորությունը, px |
| `majorEvery` | `0` | Յուրաքանչյուր N-րդ նշագիծը երկար է |
| `minorTicks` | `0`, `labels`-ով՝ `3` | Կարճ զարդային նշագծեր քայլերի միջև |
| `exclude` | — | Արժեքներ, որոնց վրա սանդղակը չի կանգնում. `[720, 730]` կամ `(v) => boolean` |
| `labels` | — | Տեքստային սանդղակ. երկար նշագիծը՝ անուն, արժեքը՝ դրա համարը |
| `showValue` | `true` | Թիվը սանդղակի վերևում |
| `formatValue` | — | `(v) => string` |
| `accent` | `'#ff453a'` | Ցուցիչի գույնը |
| `theme` | `'dark'` | `'dark'` կամ `'light'` |
| `motion` | `ParzProvider`-ից | `'calm'`, `'bouncy'`, `'snappy'` |
| `name` | — | Ձևի դաշտի անունը |
| `ariaLabel` | — | Անուն էկրանի ընթերցիչների համար |
| `disabled` | `false` | Անջատված է |
