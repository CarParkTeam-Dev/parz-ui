# Parz Pager

`ParzPager`-ը էջեր են, որոնք թերթվում են սահեցմամբ։ Էջը շարժվում է ճիշտ մատի հետ, նետելուց հետո զսպանակով կանգնում է հաջորդի վրա, իսկ եզրից այն կողմ ձգվում է դիմադրությամբ։ Ներսում կարող է լինել ամեն ինչ՝ քարտեր, ներածություն, պատկերասրահ, ցուցակներ։

- **շրջանաձև**. `loop`՝ վերջին էջից հետո շերտը շարունակում է նույն ուղղությամբ դեպի առաջինը, առանց հետ գնալու; առանց `loop`-ի առաջինը՝ առաջին է, վերջինը՝ վերջին, եզրից այն կողմ՝ դիմադրություն;
- **տեսք**. `effect`՝ `'slide'`, `'scale'` (հարևանները փոքր և մարած), `'tilt'` (թեթև 3D պտույտ), `'fade'`; `peek`՝ քանի px է երևում հարևան էջերից;
- **կետեր և սլաքներ**. `dots`՝ ակտիվը ձգվում է կաթիլի պես նույն կադրում, կետին սեղմելով կարելի է անցնել; `arrows`՝ ապակե շրջանակներ եզրերին. համակարգչում հայտնվում են կաթիլի պես սավառնելիս և թաքնվում, երբ կուրսորը հեռանում է, սենսորային էկրանին միշտ երևում են; `theme`՝ մուգ կամ բաց ֆոնի համար;
- **ինքնաթերթում**. `autoplay={3000}`՝ ակտիվ կետը լցվում է ձախից ժամաչափի ընթացքում; կանգնում է, երբ էջին դիպչում են, սավառնում կամ ֆոկուսում են; `loop`-ով՝ անվերջ առաջ, առանց դրա՝ մինչև վերջինը;
- **ստվերներ**. շերտը կտրվում է միայն հորիզոնական՝ քարտերի ստվերները վերևում և ներքևում ամբողջական են;
- **ժեստ**. ուղղահայաց սահեցումը մնում է էջի ոլորում, հորիզոնականը թերթում է; նետումը՝ հարևան էջ;
- **անիվ և թաչփադ**. հորիզոնական ժեստը՝ մեկ էջ; `wheel={false}`՝ անջատել;
- **onProgress**. կոտորակային դիրք յուրաքանչյուր կադրում՝ կետերի, պարալաքսի կամ Parz Title Tabs-ի համար;
- **onRelease**. դիրքը, երբ մատը բաց թողեցին;
- **ստեղնաշար**. սլաքներ, Home / End; թաքնված էջերը ֆոկուս չեն ստանում;
- **ParzProvider**. զսպանակը՝ նախադրվածքից; `prefers-reduced-motion`-ի դեպքում՝ առանց անիմացիայի։

```tsx
import { useState } from 'react';
import { ParzProvider, ParzPager } from '@carparkteam/parz-ui';
import '@carparkteam/parz-ui/style.css';

const [index, setIndex] = useState(0);

<ParzProvider motion="bouncy">
  <ParzPager index={index} onIndexChange={setIndex} onProgress={p => moveDots(p)}>
    <Slide1 />
    <Slide2 />
    <Slide3 />
  </ParzPager>
</ParzProvider>
```

| Հատկություն | Լռելյայն | Ինչ է անում |
|---|---|---|
| `children` | — | Էջեր |
| `index` | — | Ընթացիկ էջ (կառավարվող) |
| `defaultIndex` | `0` | Սկզբնական էջ |
| `onIndexChange` | — | Էջը փոխվեց |
| `onProgress` | — | Կոտորակային դիրք յուրաքանչյուր կադրում |
| `onRelease` | — | Դիրքը, երբ մատը բաց թողեցին |
| `effect` | `'slide'` | `'slide'`, `'scale'`, `'tilt'`, `'fade'` |
| `pageWidth` | — | Էջի առավելագույն լայնությունը, px. լայն տարայում էջը կենտրոնում է, հարևանները՝ երկու կողմից |
| `peek` | `0` | Քանի px է երևում հարևաններից |
| `dots` | `false` | Կետեր էջերի տակ |
| `arrows` | `false` | Սլաքներ եզրերին |
| `loop` | `false` | Անվերջ շերտ. վերջինից հետո գալիս է առաջինը; առանց դրա եզրերը ֆիքսված են |
| `autoplay` | — | Ինքնաթերթում ամեն N մվ |
| `paused` | `false` | Դադարեցնել ինքնաթերթումը դրսից |
| `theme` | `'dark'` | Կետերի և սլաքների գույնը. `'dark'` կամ `'light'` |
| `labels` | անգլերեն | `prev`, `next`, `page` (`'Page {n}'`) |
| `gap` | `12` | Էջերի միջև տարածություն, px |
| `wheel` | `true` | Անիվ և թաչփադ |
| `motion` | `ParzProvider`-ից | `'calm'`, `'bouncy'`, `'snappy'` |
| `ariaLabel` | — | Անուն էկրանի ընթերցիչների համար |
