# Parz Ruler

`ParzRuler` — шкала с засечками под неподвижным указателем. Её тянут пальцем или мышью: после броска шкала едет по инерции и пружинит на ближайшую засечку. Над шкалой стоит число на `ParzNumberFlow`, его цифры перелистываются с размытием. Засечки у указателя светлее, к краям шкала гаснет.

- **значения**: `min`, `max`, `step` — одна засечка на шаг; `formatValue` — как показать значение (например, минуты → `'08:30'`);
- **управление**: перетаскивание с инерцией, колесо и тачпад, нажатие на засечку; за краем шкала тянется с сопротивлением;
- **клавиатура**: стрелки — на шаг (с Shift — на 10), PageUp / PageDown — на десятую часть шкалы, Home / End — к краю;
- **вид**: `tickGap` — расстояние между засечками, `majorEvery` — каждая N-я засечка длиннее, `accent` — цвет указателя, `theme`;
- **указатель** на скорости слегка расплывается вширь, как капля;
- **ParzProvider**: пружина — из пресета `calm` / `bouncy` / `snappy`;
- **меньше движения**: при `prefers-reduced-motion` шкала встаёт на место сразу;
- **форма**: `name` — значение уйдёт с формой;
- **исключения**: `exclude` — шкала проезжает эти значения и встаёт на ближайшее разрешённое (и мышью, и с клавиатуры);
- **текст**: `labels={['Ani', 'Mark', …]}` — каждая длинная засечка отвечает за имя, между ними короткие (`minorTicks`), над шкалой — имя.

```tsx
import { useState } from 'react';
import { ParzProvider, ParzRuler } from '@carparkteam/parz-ui';
import '@carparkteam/parz-ui/style.css';

const hhmm = (m: number) => `${String(m / 60 | 0).padStart(2, '0')}:${String(m % 60).padStart(2, '0')}`;
const [minutes, setMinutes] = useState(430);

<ParzProvider motion="bouncy">
  <ParzRuler value={minutes} onChange={setMinutes} min={0} max={1430} step={10} formatValue={hhmm} ariaLabel="Время" />
</ParzProvider>
```

| Проп | По умолчанию | Что делает |
|---|---|---|
| `value` | — | Значение (управляемый режим) |
| `defaultValue` | `min` | Начальное значение (неуправляемый режим) |
| `onChange` | — | Каждое новое значение, в том числе пока шкала едет |
| `onChangeEnd` | — | Когда шкала остановилась |
| `min`, `max`, `step` | `0`, `100`, `1` | Границы и шаг |
| `tickGap` | `16` | Расстояние между засечками, px |
| `majorEvery` | `0` | Каждая N-я засечка длиннее |
| `minorTicks` | `0`, с `labels` — `3` | Короткие засечки-украшения между шагами |
| `exclude` | — | Значения, на которые шкала не встаёт: `[720, 730]` или `(v) => boolean` |
| `labels` | — | Текстовая шкала: длинная засечка — имя, значение — его номер |
| `showValue` | `true` | Число над шкалой |
| `formatValue` | — | `(v) => string` |
| `accent` | `'#ff453a'` | Цвет указателя |
| `theme` | `'dark'` | `'dark'` или `'light'` |
| `motion` | из `ParzProvider` | `'calm'`, `'bouncy'`, `'snappy'` |
| `name` | — | Имя поля формы |
| `ariaLabel` | — | Имя для экранных дикторов |
| `disabled` | `false` | Отключена |
