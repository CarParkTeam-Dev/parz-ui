# Parz Avatar

`ParzAvatar` — аватар Parz UI. Показывает фото, инициалы или значок. Фото проявляется из лёгкого размытия, а пока грузится, по инициалам идёт мягкий блик. Если фото не загрузилось, остаются инициалы. Точка статуса появляется с пружиной. Кольцо «историй» бывает ярким или серым («просмотрено»).

`ParzAvatarGroup` ставит аватары стопкой. Лишние сворачиваются в «+N», при наведении стопка раздвигается и появляются имена.

- **цвет по имени**: у одного имени всегда один и тот же цвет фона;
- **статус**: `online` с пульсом, `away` (полумесяц), `busy` (черта), `offline` (кольцо);
- **кольцо**: `ring`, `ring="seen"` или свой градиент; градиент кольца течёт по кругу (`ringSpin={false}` — неподвижно);
- **счётчик**: `count` — бейдж в углу (ParzBadge);
- **кнопка или ссылка**: `onClick` / `href`, при наведении аватар подрастает с пружиной;
- **ParzProvider**: пружины берутся из общего пресета `calm` / `bouncy` / `snappy`;
- **меньше движения**: при `prefers-reduced-motion` всё меняется без анимации, пульс становится тихим миганием.

```tsx
import { ParzProvider, ParzAvatar, ParzAvatarGroup } from '@carparkteam/parz-ui';
import '@carparkteam/parz-ui/style.css';

<ParzProvider motion="bouncy">
  <ParzAvatar src={user.photo} name="Ани Петросян" size="lg" status="online" statusLabel="в сети" />

  <ParzAvatarGroup max={4} onMoreClick={showAll} ariaLabel="Участники">
    {team.map(u => <ParzAvatar key={u.id} src={u.photo} name={u.name} />)}
  </ParzAvatarGroup>
</ParzProvider>
```

## ParzAvatar

| Проп | По умолчанию | Что делает |
|---|---|---|
| `src` | — | Адрес фото |
| `alt` | `name` | Описание фото для экранных дикторов |
| `name` | — | Имя: из него берутся инициалы, цвет фона и подсказка |
| `initials` | из `name` | Свои инициалы (1–2 знака) |
| `icon` | силуэт | Значок, если нет ни фото, ни имени: встроенный, `'ms:имя'`, `'mi:имя'` или ReactNode |
| `size` | `'md'` | `'xs'` 24, `'sm'` 32, `'md'` 40, `'lg'` 56, `'xl'` 72 или число в пикселях |
| `shape` | `'circle'` | `'circle'`, `'rounded'`, `'square'` |
| `color` | по имени | Цвет фона инициалов |
| `textColor` | белый | Цвет инициалов |
| `status` | — | `'online'`, `'away'`, `'busy'`, `'offline'` |
| `statusLabel` | — | Текст статуса для экранных дикторов |
| `statusColor` | — | Свой цвет точки |
| `statusPulse` | `true` | Пульс у `online` |
| `ring` | — | `true` — яркое кольцо, `'seen'` — серое, строка — свой цвет или градиент |
| `ringSpin` | `true` | Градиент яркого кольца плавно течёт по кругу; `false` — неподвижно |
| `count` | — | Счётчик в углу; 0 прячет его |
| `countMax` | `99` | Больше — показывается «99+» |
| `tooltip` | в группе — `true` | Подсказка при наведении: `true` — имя, или свой текст |
| `onClick` / `href` / `target` | — | Аватар становится кнопкой или ссылкой |
| `theme` | `'dark'` | Фон под аватаром: от него обводка статуса, счётчика и разделитель в группе |
| `surfaceColor` | — | Свой цвет этого фона |
| `motion` | из `ParzProvider` | `'calm'`, `'bouncy'`, `'snappy'` |
| `disabled` | `false` | Отключён |

Кольцо добавляет вокруг аватара отступ, равный своей толщине, — соседние элементы его не перекрывают.

## Смена аватара

С `editable` нажатие на аватар открывает окно выбора: инициалы, готовые рисунки и кнопка «Загрузить фото». При наведении на аватар появляется значок камеры.

```tsx
<ParzAvatar
  src={user.photo}
  name={user.name}
  size="xl"
  editable
  onUpload={file => api.uploadAvatar(file)} // Promise<string> — адрес готового фото
  onUploadError={() => toast('Не удалось загрузить фото')}
  onChange={v => save(v)}
/>
```

Пока идёт `onUpload`, выбранное фото уже стоит в аватаре, но размыто, и по нему бегут точки. Когда придёт адрес, резкое фото проявится из-под превью.

| Проп | По умолчанию | Что делает |
|---|---|---|
| `editable` | `false` | Включает окно выбора |
| `presets` | `PARZ_AVATAR_PRESETS` | Готовые картинки в окне, массив адресов |
| `onChange` | — | `{ kind: 'preset', src }`, `{ kind: 'initials' }` или `{ kind: 'upload', file, src }` |
| `onUpload` | — | `(file) => Promise<string> \| string` — загрузить файл и вернуть адрес |
| `onUploadError` | — | `(error, file)` — загрузка не удалась, аватар уже вернулся к прежнему виду |
| `value` | — | Управляемый режим: строка — фото, `null` — инициалы. Аватар показывает только `value`, выбор лишь вызывает `onChange` |
| `accept` | `'image/*'` | Какие файлы можно выбрать |
| `labels` | английские | `title`, `initials`, `upload`, `uploading`, `edit`, `preset` (`'Avatar {n}'`) |

Без `value` аватар меняется сам сразу после выбора, а новый `src` снаружи сбрасывает выбор.

Без `onUpload` фото показывается прямо из файла по временному адресу `blob:`. Он работает, пока аватар на странице, и освобождается, когда фото сменили или аватар убрали. Сохранять такой адрес на сервере бесполезно — для настоящей загрузки передайте `onUpload`.

`ref` указывает на сам аватар (кнопку, ссылку или `span`) — например, чтобы поставить на него фокус.

## ParzAvatarGroup

| Проп | По умолчанию | Что делает |
|---|---|---|
| `children` | — | `ParzAvatar`; размер, форма, фон и движение группы передаются им, если не задано своё |
| `max` | все | Сколько аватаров показать; остальные — «+N» |
| `total` | число `children` | Сколько всего людей, если в `children` только часть |
| `size`, `shape` | `'md'`, `'circle'` | Для всех аватаров группы |
| `spacing` | `'normal'` | Наложение: `'tight'`, `'normal'`, `'loose'` |
| `spread` | `true` | Раздвигать стопку при наведении и фокусе |
| `tooltips` | `true` | Подсказки с именами |
| `onMoreClick` | — | Нажатие на «+N»; без него «+N» — просто надпись |
| `moreLabel` | `n => '+n'` | Текст «+N» для экранных дикторов |
| `theme`, `surfaceColor`, `motion` | — | Как у `ParzAvatar` |
| `ariaLabel` | — | Имя группы для экранных дикторов |
