# Parz Progress

`ParzProgress` — индикатор прогресса Parz UI: полоса или кольцо. Когда значение меняется, заливка перетекает к нему на мягкой пружине, а не прыгает. Ничего резкого.

- **смена значения** — заливка и проценты плавно перетекают к новому значению;
- **блик** — по заливке полосы медленно течёт мягкий блик;
- **неизвестно сколько** — без `value` (или с `indeterminate`) по полосе течёт жидкая капля, а дуга кольца дышит и вращается;
- **100%** — дорожка один раз мягко вспыхивает (`celebrate`);
- **меньше движения** — при `prefers-reduced-motion` значение показывается сразу, а режим «неизвестно сколько» просто мерцает.

У компонента `role="progressbar"` и `aria-valuenow`, поэтому экранные дикторы озвучивают прогресс.

```tsx
import { ParzProgress } from '@carparkteam/parz-ui';
import '@carparkteam/parz-ui/style.css';

<ParzProgress value={progress} label="Загрузка" />

<ParzProgress variant="ring" value={progress} size="lg" />

// неизвестно сколько
<ParzProgress indeterminate label="Подождите…" />
```

| Пропс | По умолчанию | Что делает |
|---|---|---|
| `value` | — | Текущее значение. Без него — режим «неизвестно сколько» |
| `max` | `100` | Максимум |
| `indeterminate` | `false` | Неизвестно сколько: по полосе течёт капля, дуга кольца вращается |
| `variant` | `'bar'` | `'bar'` (полоса) или `'ring'` (кольцо) |
| `size` | `'md'` | Высота полосы `'sm'` (4 px), `'md'` (8 px), `'lg'` (12 px); кольцо `28`, `44`, `68` px |
| `label` | — | Подпись над полосой; у кольца — рядом или под ним |
| `labelPosition` | `'end'` | Только для кольца: `'end'` — справа, `'start'` — слева, `'bottom'` — под кольцом |
| `showValue` | `true`, если есть `value` | Показывать значение: справа от подписи или в центре кольца (у кольца `sm` — нет) |
| `formatValue` | проценты | `(value, max) => ReactNode` |
| `status` | `'default'` | `'success'` — успех, `'warning'` — внимание (заливка спокойно дышит), `'error'` — ошибка (один мягкий вздрог), `'paused'` — задержка (цвет приглушён, движение замирает). У успеха, ошибки и паузы вместо числа — значок: галочка, `!`, пауза |
| `successMorph` | `false` | **Бета.** На 100% при `status="success"` полоса стягивается в каплю и превращается в круг с галочкой; кольцо заливается цветом с галочкой. Обратно — так же плавно |
| `celebrate` | `true` | Мягкая вспышка, когда дошли до конца |
| `accent` | `#6ee7a0` | Цвет заливки |
| `trackColor` | полупрозрачный серый | Цвет дорожки |
| `ariaLabel` | — | Название для экранных дикторов, если нет `label` |
| `className` / `style` | — | На корневой элемент |

## CSS-переменные

`--pz-pg-accent` (заливка), `--pz-pg-success`, `--pz-pg-warning`, `--pz-pg-error`, `--pz-pg-paused` (цвета состояний), `--pz-pg-track` (дорожка), `--pz-pg-h` (высота полосы).

```css
.uploads { --pz-pg-accent: #7aa7ff; --pz-pg-h: 6px; }
```
