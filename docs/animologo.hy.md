# AnimoLogo

`AnimoLogo`-ը Parz UI-ի առանձին կոմպոնենտ է՝ լոգո-մակագրություն, որտեղ յուրաքանչյուր տառ փոքրիկ լույս է, կենտրոնին մոտ տառերն ավելի պայծառ են։ Աշխատում է ինքնուրույն ցանկացած տեղում և հարմար է վերնագոտու `logo` սլոտին։

- **հայտնվել** — տառերը դուրս են գալիս մշուշից, դրանց վրայով անցնում է փայլ.
- **սավառում** — շեշտի գույնի ալիք.
- **սեղմած պահել** — տառերը հավաքվում ու մարում են, ներքևում լցվում է գիծ, `holdDuration`-ից հետո վառվում են շեշտի գույնով.
- **բաց թողնել** — սահուն ցրվում են և կարճ ժամանակով պայծառանում, առանց կտրուկ բռնկումների.
- **հանգիստ** — հազվադեպ մեղմ առկայծում։

```tsx
import { ParzMenu, AnimoLogo } from '@parz/ui';

<ParzMenu items={items} desktop={{ logo: <AnimoLogo text="CARPARK" /> }} />

<AnimoLogo text="PARZ" size={22} onClick={() => navigate('/')} onHoldComplete={openAbout} />
```

| Պրոպ | Լռելյայն | Ինչ է անում |
|---|---|---|
| `text` | `'PARZ'` | Լոգոյի տեքստը |
| `size` | `13` | Տառերի չափը՝ px կամ ցանկացած CSS արժեք |
| `intro` / `introDelay` | `true` / `150` | Հայտնվելու անիմացիա մոնտաժելիս և դրա ուշացումը, մվ |
| `idle` | `true` | Հազվադեպ առկայծում հանգստի վիճակում |
| `hoverWave` | `true` | Ալիք մկնիկով սավառելիս |
| `holdEffect` / `holdDuration` | `true` / `1000` | Սեղմած պահելու էֆեկտը և որքան պահել, մվ |
| `onHoldComplete` | — | Պահեցին մինչև վերջ՝ օրինակ, բացել «Հավելվածի մասին» կամ թաքնված մենյու |
| `onClick` | — | Սովորական սեղմում կամ Enter։ Դրանով լոգոն դառնում է կոճակ |
| `dimColor` / `brightColor` | `#7d7d87` / `#fafafa` | Եզրային և կենտրոնական տառերի գույնը։ Բաց էջի համար փոխեք տեղերով |
| `hoverColor` | `#fff` | Գույնը սավառելիս |
| `accent` | `#6ee7a0` | Ալիք, պահելու գիծ և փայլ |
| `spacing` | `0.34` | Տառերի միջև հեռավորություն, em |
| `ariaLabel` | `text` | Պիտակ ընթերցիչի համար |

Տառատեսակը ժառանգվում է ծնողից, հաստությունը՝ 700։ Համակարգային «նվազեցնել շարժումը» կարգավորման դեպքում մնում է միայն գույնի փոփոխությունը։
