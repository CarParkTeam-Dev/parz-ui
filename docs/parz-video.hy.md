# Parz Video

`ParzVideo`-ն Parz UI-ի տեսանվագարկիչն է։ Կառավարման վահանակը հեղուկ ապակի է, որը լողում է տեսանյութի վրա և մեղմ թաքնվում է դիտելիս։ Ոչինչ կտրուկ։

- **ոլորում** — գիծը սահուն հոսում է ամեն կադրում, այլ ոչ թե ցատկում վայրկյանը չորս անգամ. սլաքը մոտեցնելիս այն հաստանում է, երևում են բռնակը և ժամանակի հուշումը;
- **կենտրոն** — ինչպես Apple-ի նվագարկիչում՝ ապակե «դիտել/դադար» կոճակ, կողքերին −10 և +10 (նեղ նվագարկիչում ±10-ը վահանակում է); երևում է վահանակի հետ;
- **շապիկ** — `poster`-ը տեսանյութի վրա է և սահուն անհետանում է մեկնարկին;
- **ձայնի նշան** — `audioBadge="Dolby Atmos"`-ը ցույց է տալիս Dolby Atmos նշանը, `"Spatial Audio"`-ն՝ տարածական ձայնի պատկերակ, այլ տեքստ՝ ալիքներով պատկերակ;
- **պատկերակներ** — «դիտել», «դադար» և «կրկին», ձայնը և ամբողջ էկրանը վերածվում են իրար;
- **վահանակ** — `hideDelay`-ից հետո առանց մկնիկի շարժման մեղմ անհետանում է, դադարի ժամանակ միշտ երևում է;
- **ձայն** — սահիչը բացվում է ձայնի կոճակի վրա սլաքը պահելիս, լայնությունը սահուն փոխվում է;
- **կարգավորումներ** — ատամնանիվը բացում է ապակե ընտրացանկ՝ որակ, արագություն, ենթագրեր և կրկնում։ Էջերը սահում են կողքից, բարձրությունը սահուն փոխվում է, առանց մոդալ պատուհանների;
- **որակ** — փոխելիս ժամանակը և դադարը պահպանվում են, իսկ վերջին կադրը սահուն լուծվում է նորի մեջ;
- **գլուխներ** — գիծը բաժանվում է հատվածների, գլխի անունը երևում է հուշման մեջ և ժամանակի կողքին;
- **կադրի նախադիտում** — գծի վերևում երևում է այն կետի կադրը, որտեղ սլաքն է;
- **ենթագրեր** — WebVTT՝ նվագարկիչի ոճով; երբ վահանակը երևում է, տողը մեղմ բարձրանում է;
- **±10 վայրկյան** — ոլորման կոճակներ; ժամանակի վրա սեղմելը ցույց է տալիս մնացածը;
- **հուշումներ** — դադարի, ոլորման և ձայնի փոփոխության ժամանակ կենտրոնում մեղմ հայտնվում է պատկերակ;
- **սպասում** — մինչև մեկնարկը, մինչ բուֆերը լցվում է, կենտրոնական կոճակում կետեր են վազում մուգ մշուշոտ ապակու վրա; եթե դիտելիս տեսանյութը բեռնվում է, կենտրոնում աղեղ է պտտվում;
- **հեռախոս** — հպումը ցույց է տալիս կամ թաքցնում վահանակը, եզրին կրկնակի հպումը ոլորում է 10 վայրկյան; նեղ նվագարկիչում ձայնը միայն կոճակ է;
- **աջ սեղմում** — սեփական ընտրացանկ սլաքի մոտ՝ Parz UI նշան, «by CarPark Team», տարբերակը և «Parz UI-ի մասին» (բացում է dev.carpark.am/parz-ui նոր ներդիրում);
- **քիչ շարժում** — `prefers-reduced-motion`-ի դեպքում անցումները գրեթե ակնթարթային են։

## Դասավորություն

Տեսանյութի վրայի ամեն ինչ առանձին ապակե պարկուճներ են՝ առանց եզրագծի, խորությունը տալիս է արտաքին հստակ ստվերը։ Երևում և թաքնվում են միասին։

- **վերևում ձախ** — վերնագիր, որակի նշան (4K / HD) և ընթացիկ գլուխը;
- **վերևում աջ** — ձայնի ձևաչափի նշան և ձայնի ուժգնություն. համակարգչում՝ կլոր կոճակ, սահիչը բացվում է սլաքը պահելիս;
- **կենտրոնում** — «դիտել/դադար» և −10 / +10, ինչպես Apple-ի նվագարկիչում;
- **գծի վերևում աջ** — որակ, ենթագրեր, արագություն և «ավելին» (կրկնում), կողքին՝ նկար նկարի մեջ, հեռարձակում և ամբողջ էկրան;
- **ներքևում** — ժամանակագիծը իր պարկուճում՝ ժամանակ, գիծ, մնացածը (սեղմել՝ ընդհանուր տևողություն)։

**Նեղ նվագարկիչ (մինչև 460 px, հեռախոս).** վերևում ձախ՝ նկար նկարի մեջ և հեռարձակում, վերևում աջ՝ ձայնի կոճակ (միայն անջատել / միացնել), ներքևում աջ՝ «…» կոճակը և նրանից աջ՝ ամբողջ էկրան; «…» ընտրացանկում պատկերակներով՝ որակ, արագություն, ենթագրեր, կրկնում։ Ցածր նվագարկիչում վերնագիրը թաքնվում է։

```tsx
import { ParzVideo } from '@carparkteam/parz-ui';
import '@carparkteam/parz-ui/style.css';

<ParzVideo src="/video.mp4" poster="/poster.jpg" title="Մեր տեսահոլովակը" />

// որակ, գլուխներ և ենթագրեր
<ParzVideo
  sources={[
    { src: '/video-2160.mp4', label: '2160p' }, // 4K
    { src: '/video-1080.mp4', label: '1080p' }, // HD
    { src: '/video-720.mp4', label: '720p' }
  ]}
  chapters={[{ start: 0, title: 'Ներածություն' }, { start: 42, title: 'Հիմնական' }]}
  tracks={[{ src: '/subs.hy.vtt', label: 'Հայերեն', srclang: 'hy', default: true }]}
/>
```

## Ցանկ

Փոխանցեք `playlist`, և նվագարկիչը տեսանյութերը կխաղա իրար հետևից։ Յուրաքանչյուրն ունի իր `src` կամ `sources`, `title`, `poster`, `chapters`, `tracks` և ոչ պարտադիր `duration` ցանկի համար։ Կենտրոնում −10 / +10-ի կողքերին «նախորդը» և «հաջորդը» են (նեղ նվագարկիչում՝ դրանց փոխարեն). ցանկի կոճակը բացում է տեսանյութերը մանրապատկերներով, ընթացիկը նշված է։ Ավարտից մի քանի վայրկյան առաջ հայտնվում է «Հաջորդը» քարտը հետհաշվարկի օղակով. սեղմեք՝ հաջորդը կսկսվի անմիջապես, չեղարկեք՝ տեսանյութը պարզապես կավարտվի։ Փոխելիս նվագարկումը շարունակվում է, իսկ վերջին կադրը լուծվում է նորի մեջ։

```tsx
<ParzVideo
  playlist={[
    { src: '/intro.mp4', title: 'Ներածություն', poster: '/intro.jpg', duration: 64 },
    { src: '/bay.mp4', title: 'Ծովախորշ', poster: '/bay.jpg', duration: 27 }
  ]}
/>
```

Տվյալները կարող են գալ ձեր API-ից. յուրաքանչյուր գրառում դարձրեք `ParzVideoItem`։ Յուրաքանչյուր տեսանյութ պահում է իր որակները, ենթագրերը և գլուխները. `index`-ով և `onIndexChange`-ով դուք եք կառավարում, թե որն է խաղում (օրինակ՝ առաջընթացը հիշելու համար)։

```tsx
import { useEffect, useState } from 'react';
import { ParzVideo, type ParzVideoItem } from '@carparkteam/parz-ui';

// ինչ է վերադարձնում ձեր API-ն — ձևը ցանկացած է, սա օրինակ է
type ApiVideo = {
  id: string; name: string; cover: string; length: number;
  files: { url: string; height: number }[];
  subtitles: { url: string; lang: string; name: string }[];
  parts: { at: number; name: string }[];
};

const toItem = (v: ApiVideo): ParzVideoItem => ({
  title: v.name,
  poster: v.cover,
  duration: v.length,
  // յուրաքանչյուր տեսանյութ ունի իր որակները, ենթագրերը և գլուխները
  sources: v.files.sort((a, b) => b.height - a.height).map(f => ({ src: f.url, label: `${f.height}p` })),
  tracks: v.subtitles.map(s => ({ src: s.url, srclang: s.lang, label: s.name })),
  chapters: v.parts.map(p => ({ start: p.at, title: p.name }))
});

export function Course({ id }: { id: string }) {
  const [items, setItems] = useState<ParzVideoItem[]>([]);
  const [index, setIndex] = useState(0);
  useEffect(() => {
    fetch(`/api/courses/${id}/videos`).then(r => r.json()).then((list: ApiVideo[]) => setItems(list.map(toItem)));
  }, [id]);
  if (!items.length) return null;
  return (
    <ParzVideo
      playlist={items}
      index={index}
      onIndexChange={i => { setIndex(i); /* օրինակ՝ պահել առաջընթացը. fetch('/api/progress', …) */ }}
      upNextSeconds={10}
    />
  );
}
```

## Ստեղներ

Երբ նվագարկիչը ֆոկուսում է. `Բացատ` կամ `K` — դադար, `←` / `→` — 5 վայրկյան հետ և առաջ, `J` / `L` — `skipSeconds` քայլով, `0`–`9` — անցում հոլովակի 0–90%, `C` — ենթագրեր, `↑` / `↓` — ձայն, `M` — ձայնը միացնել/անջատել, `F` — ամբողջ էկրան, `Esc` — փակել կարգավորումների ընտրացանկը, `Shift+N` / `Shift+P` — ցանկի հաջորդ և նախորդ տեսանյութը։ Ոլորման գծի վրա `Home` / `End` — սկիզբ և վերջ։

| Հատկություն | Լռելյայն | Ինչ է անում |
|---|---|---|
| `src` | — | Տեսանյութի հասցեն (կարելի է չնշել, եթե կա `sources`) |
| `sources` | — | Որակի տարբերակներ՝ `{ src, label, type?, badge? }[]`։ Ատամնանիվի կողքի նշանը որոշվում է պիտակից՝ `2160p` և ավելի — **4K**, `720p` և ավելի — **HD**; սեփականը՝ `badge`, դատարկ տող՝ առանց նշանի |
| `defaultQuality` | `'auto'` | Որ որակով սկսել. `sources`-ի համարը կամ `'auto'` — նվագարկիչն ինքն է ընտրում ըստ իր չափի, էկրանի խտության և ցանցի (տրաֆիկի խնայում, 2g/3g, արագություն) և իջնում է, եթե տեսանյութը կախվում է։ Ձեռքով ընտրությունն անջատում է ավտոմատը, ընտրացանկի «Ավտո» կետը՝ միացնում |
| `chapters` | — | Գլուխներ՝ `{ start, title }[]`, `start`-ը վայրկյաններով |
| `tracks` | — | WebVTT ենթագրեր՝ `{ src, label, srclang, default? }[]`։ Սկզբում անջատված են; `default`-ը այն ուղին է, որը միացնում է C ստեղնը։ Այլ դոմենից պետք է CORS |
| `previews` | `true` | Կադր գծի վերևում (տեսանյութը բեռնում է երկրորդ անգամ, միայն անհրաժեշտ կադրերը) |
| `poster` | — | Շապիկ մինչև մեկնարկը; մեղմ հայտնվում է նկարը բեռնվելիս, սահուն անհետանում է, երբ տեսանյութը սկսվում է, և վերադառնում է ավարտին (եթե `loop` չկա) |
| `title` | — | Վերնագիր վերևում; թաքնվում է վահանակի հետ |
| `audioBadge` | — | Ձայնի ձևաչափի նշան վերևի աջ անկյունում. երբ վահանակը թաքնվում է, սահում է անկյուն, մնում ևս 3 վ և անհետանում։ `'Dolby Atmos'`՝ Dolby Atmos նշան, `'Spatial Audio'`՝ տարածական ձայնի պատկերակ, այլ տեքստ (`'5.1'`…)՝ ալիքներով |
| `autoPlay` / `muted` / `loop` | `false` | Ինչպես `<video>`-ում։ Զննարկիչներն ինքնուրույն միացնում են միայն առանց ձայնի |
