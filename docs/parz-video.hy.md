# Parz Video

`ParzVideo`-ն Parz UI-ի տեսանվագարկիչն է։ Կառավարման վահանակը հեղուկ ապակի է, որը լողում է տեսանյութի վրա և մեղմ թաքնվում է դիտելիս։ Ոչինչ կտրուկ։

- **ոլորում** — գոտին հոսում է յուրաքանչյուր կադրում. սավառնելիս հաստանում է, երևում են սահիչը և հուշումը՝ ժամանակով, գլխով և այդ տեղի կադրով;
- **կենտրոն** — ինչպես Apple-ի նվագարկիչում. ապակե «դիտել/դադար» կոճակ, կողքերին −10 և +10, ցանկում՝ «նախորդը» և «հաջորդը»;
- **շապիկ** — `poster`-ը տեսանյութի վրա է, մեկնարկին սահուն լուծվում է և վերադառնում է վերջում;
- **ձայնի նշան** — `audioBadge="Dolby Atmos"`՝ Dolby Atmos նշանը, `"Spatial Audio"`՝ ծավալային ձայնի պատկերակը, այլ տեքստ՝ ալիքներով նշան;
- **կարգավորումների կոճակներ** — որակը, ձայնը, ենթագրերը և արագությունը վահանակին են առանձին կոճակներով (`buttons`-ը ձայնը, ենթագրերը և արագությունը տեղափոխում է «Ավելին»). «Ավելին»-ում՝ կրկնում և «Կիսվել». ընտրացանկը ապակե պատուհան է, էջերը մտնում են կողքից, բարձրությունը հոսում է;
- **կոճակների հուշումներ** — մկնիկը սավառնելիս կոճակի վերևում երևում է անունը և առանց թարթելու հոսում է հարևան կոճակին;
- **որակ** — լռելյայն «Ավտո». նվագարկիչն ընտրում է ֆայլը ըստ չափի, էկրանի խտության և ցանցի և իջնում է, եթե տեսանյութը կախվում է. փոխելիս կադրը լուծվում է, ժամանակը և դադարը պահպանվում են;
- **ձայն** — մի քանի լեզու (`audio`), փոխվում է որակի պես;
- **գլուխներ** — բարակ գծեր ամբողջական սանդղակին. անցած գիծը ստանում է շեշտի գույնը;
- **ենթագրեր** — WebVTT նվագարկիչի ոճով, լռելյայն անջատված. հեռախոսում ավելի փոքր են և մեղմ լուծվում են, քանի դեռ վահանակը երևում է;
- **ցանկ** — `playlist`. տեսանյութերի ժապավեն ներքևից, «Հաջորդը» քարտ հետհաշվարկով, սահուն փոփոխություն;
- **հիշել** — `remember`. տեղը, սերիան և դիտողի կարգավորումները. հաջորդ անգամ՝ «Շարունակել · 15:12»;
- **ձայնի ուժգնություն** — համակարգչում սկսում է 70%-ից և սավառնելիս բացվում է սահիչի. հեռախոսում ձայնը կառավարում է սարքը;
- **հեռարձակում և «նկար նկարում»** — սև էկրանի փոխարեն պաստառ շապիկով և տեսանյութը վերադարձնելու կոճակով;
- **հուշումներ կենտրոնում** — ոլորման և ձայնի պատկերակները կարճ բռնկվում են, տեքստը («Հղումը պատճենված է», որակ) մնում է մոտ երկու վայրկյան;
- **սպասում** — մեկնարկից առաջ կենտրոնական կոճակում վազում են կետեր, ցուցադրման ժամանակ բեռնվելիս պտտվում է աղեղ. iOS Safari-ում բեռնումը չի կախվում;
- **հեռախոս** — հպումը ցույց է տալիս կամ թաքցնում վահանակը (մատը բարձրացնելը չի թաքցնում), եզրին կրկնակի հպումը ոլորում է 10 վայրկյան. iPhone-ի համակարգային ամբողջ էկրանը պահպանում է արագությունը և ենթագրերը;
- **աջ սեղմում** — սեփական ընտրացանկ կուրսորի մոտ. Parz UI նշանը, «by CarPark Team», տարբերակը և «Parz UI-ի մասին» (բացում է dev.carpark.am/parz-ui նոր ներդիրում);
- **անիմացիայի երկու ոճ** — `motion="liquid"` (տարրերը հայտնվում և թաքնվում են կաթիլների պես, թաքցնելը՝ ճշգրիտ հակառակ անիմացիա) և `motion="fade"`;
- **քիչ շարժում** — `prefers-reduced-motion`-ի դեպքում անցումները գրեթե ակնթարթային են։

## Դասավորություն

Տեսանյութի վրա ամեն ինչ առանձին ապակե պարկուճներ են առանց եզրագծի, խորությունը տալիս է սուր արտաքին ստվերը։ Հայտնվում և թաքնվում են միասին։

- **վերևում ձախ** — վերնագիրը, որակի նշանը (4K / HD) և ընթացիկ գլուխը;
- **վերևում աջ** — ձայնի ձևաչափի նշանը և ուժգնությունը. համակարգչում կլոր ձայնի կոճակ, սահիչը բացվում է սավառնելիս;
- **կենտրոնում** — «դիտել/դադար» և −10 / +10 (ցանկում նաև «նախորդը» և «հաջորդը»);
- **սանդղակի վերևում ձախ** — նկար նկարում և հեռարձակում;
- **սանդղակի վերևում աջ** — կարգավորումների կոճակներ (առավելագույնը 5՝ որակ, ձայն, ենթագրեր, արագություն, ցանկ) և «Ավելին», աջում՝ ամբողջ էկրան;
- **ներքևում** — սանդղակն իր պարկուճում. ժամանակ, գոտի, մնացած ժամանակ (սեղմում՝ ընդհանուր տևողություն)։

**Նեղ նվագարկիչ (մինչև 460 px, հեռախոս).** վերևում աջ՝ ձայնի կոճակ (միայն անջատել / միացնել); սանդղակի վերևում ձախ՝ նկար նկարում և հեռարձակում, աջ՝ «…» և ամբողջ էկրան; «…»-ում պատկերակներով՝ ցանկ, որակ, ձայն, ենթագրեր, արագություն, «Կիսվել», կրկնում; ցանկում «նախորդը / հաջորդը» կանգնում են ±10-ի փոխարեն։

**Շատ փոքր նվագարկիչ (նեղ և մինչև 230 px բարձրությամբ).** աջ կոճակները շարվում են սանդղակի հետ, կենտրոնը փոքրանում է, նկար նկարում և հեռարձակումը տեղափոխվում են «…», ընտրացանկը կարող է ծածկել սանդղակը. եթե նվագարկիչը 280 px-ից նեղ է, ներքևի պարկուճում մնում է միայն ընթացիկ ժամանակը։

```tsx
import { ParzVideo } from '@carparkteam/parz-ui';
import '@carparkteam/parz-ui/style.css';

<ParzVideo src="/video.mp4" poster="/poster.jpg" title="Մեր տեսահոլովակը" />

// որակ, գլուխներ և ենթագրեր
<ParzVideo
  sources={[
    { src: '/video-2160.mp4', label: '2160p' }, // 4K
    { src: '/video-1080.mp4', label: '1080p' }, // HD
    { src: '/video-720.mp4', label: '720p' }
  ]}
  chapters={[{ start: 0, title: 'Ներածություն' }, { start: 42, title: 'Հիմնական' }]}
  tracks={[{ src: '/subs.hy.vtt', label: 'Հայերեն', srclang: 'hy', default: true }]}
/>
```

> [!NOTE]
> **Շուտով**
> - **Ուղիղ եթեր** — նվագարկիչը կցուցադրի ուղիղ հեռարձակումներ. LIVE նշան, անցում ուղիղ եթերին և ոլորում հասանելի պատուհանի սահմաններում։
> - **Գովազդ** — գովազդ տեսանյութի մեկնարկից առաջ և միջանկյալ գովազդ դիտելու ընթացքում։

## Ձայն մի քանի լեզվով

Սերիալների և կրկնօրինակման համար փոխանցեք `audio`. յուրաքանչյուր լեզու տեսանյութի իր տարբերակն է՝ մեկ ֆայլ կամ իր որակները։ Փոխելիս ժամանակը և դադարը պահպանվում են, կադրը լուծվում է ինչպես որակը փոխելիս. «Ավտո» որակն աշխատում է ընտրված լեզվի ներսում։ Ցանկում դիտողի ընտրությունն անցնում է հաջորդ սերիաներին (ըստ `lang`-ի, այլապես ըստ անվան)։ Կոճակը վահանակին է ենթագրերի կողքին. `buttons={{ audio: 'more' }}`-ը տեղափոխում է այն «Ավելին» (նեղ նվագարկիչում այն միշտ այնտեղ է)։

```tsx
<ParzVideo
  audio={[
    { label: 'English', lang: 'en', sources: [{ src: '/e1.en.1080.mp4', label: '1080p' }, { src: '/e1.en.720.mp4', label: '720p' }] },
    { label: 'Հայերեն', lang: 'hy', src: '/e1.hy.mp4' }
  ]}
  defaultAudio="hy"
/>
```

## Դիտումը հիշելը

`remember`-ով նվագարկիչը դիտողի բրաուզերում (`localStorage`) պահում է սերիան և տեղը, ձայնի լեզուն, ենթագրերը, որակը (կամ «Ավտո»), արագությունը և ձայնի ուժգնությունը։ Հաջորդ անգամ «դիտել»-ի փոխարեն հայտնվում է «Շարունակել · Սերիա 2 · 15:12 · Կրկնօրինակում» պարկուճը և փոքր «Սկզբից»-ը, իսկ սանդղակին արդեն նշված է կանգառի տեղը։ Տեղը պահվում է մի քանի վայրկյանը մեկ, դադարի, կարգավորումները փոխելիս և ներդիրը փակելիս։ Սկիզբը (10 վ-ից պակաս) չի հիշվում. 95%-ից ավել դիտված տեսանյութը համարվում է դիտված, և ցանկում առաջարկվում է հաջորդ սերիան։

```tsx
<ParzVideo
  playlist={episodes}
  remember="series-42"                  // own key for every film or series
  rememberOptions={{ volume: false }}   // optional: what not to remember
/>
```

Առաջընթացը ձեր սերվերում պահելու համար փոխանցեք `initialState` և պահեք այն, ինչ գալիս է `onProgress`-ով.

```tsx
<ParzVideo
  initialState={progressFromServer}       // { i, t, audio, sub, q, rate, … }
  onProgress={state => fetch('/api/progress', { method: 'POST', body: JSON.stringify(state) })}
/>
```

## Ցանկ

Փոխանցեք `playlist`, և նվագարկիչը տեսանյութերը կխաղա իրար հետևից։ Յուրաքանչյուրն ունի իր `src` կամ `sources`, `title`, `poster`, `chapters`, `tracks` և ոչ պարտադիր `duration` ցանկի համար։ Կենտրոնում −10 / +10-ի կողքերին «նախորդը» և «հաջորդը» են (նեղ նվագարկիչում՝ դրանց փոխարեն). ցանկի կոճակը բացում է տեսանյութերը մանրապատկերներով, ընթացիկը նշված է։ Ավարտից մի քանի վայրկյան առաջ հայտնվում է «Հաջորդը» քարտը հետհաշվարկի օղակով. սեղմեք՝ հաջորդը կսկսվի անմիջապես, չեղարկեք՝ տեսանյութը պարզապես կավարտվի։ Փոխելիս նվագարկումը շարունակվում է, իսկ վերջին կադրը լուծվում է նորի մեջ։

```tsx
<ParzVideo
  playlist={[
    { src: '/intro.mp4', title: 'Ներածություն', poster: '/intro.jpg', duration: 64 },
    { src: '/bay.mp4', title: 'Ծովախորշ', poster: '/bay.jpg', duration: 27 }
  ]}
/>
```

Տվյալները կարող են գալ ձեր API-ից. յուրաքանչյուր գրառում դարձրեք `ParzVideoItem`։ Յուրաքանչյուր տեսանյութ պահում է իր որակները, ենթագրերը և գլուխները. `index`-ով և `onIndexChange`-ով դուք եք կառավարում, թե որն է խաղում (օրինակ՝ առաջընթացը հիշելու համար)։

```tsx
import { useEffect, useState } from 'react';
import { ParzVideo, type ParzVideoItem } from '@carparkteam/parz-ui';

// ինչ է վերադարձնում ձեր API-ն — ձևը ցանկացած է, սա օրինակ է
type ApiVideo = {
  id: string; name: string; cover: string; length: number;
  files: { url: string; height: number }[];
  subtitles: { url: string; lang: string; name: string }[];
  parts: { at: number; name: string }[];
};

const toItem = (v: ApiVideo): ParzVideoItem => ({
  title: v.name,
  poster: v.cover,
  duration: v.length,
  // յուրաքանչյուր տեսանյութ ունի իր որակները, ենթագրերը և գլուխները
  sources: v.files.sort((a, b) => b.height - a.height).map(f => ({ src: f.url, label: `${f.height}p` })),
  tracks: v.subtitles.map(s => ({ src: s.url, srclang: s.lang, label: s.name })),
  chapters: v.parts.map(p => ({ start: p.at, title: p.name }))
});

export function Course({ id }: { id: string }) {
  const [items, setItems] = useState<ParzVideoItem[]>([]);
  const [index, setIndex] = useState(0);
  useEffect(() => {
    fetch(`/api/courses/${id}/videos`).then(r => r.json()).then((list: ApiVideo[]) => setItems(list.map(toItem)));
  }, [id]);
  if (!items.length) return null;
  return (
    <ParzVideo
      playlist={items}
      index={index}
      onIndexChange={i => { setIndex(i); /* օրինակ՝ պահել առաջընթացը. fetch('/api/progress', …) */ }}
      upNextSeconds={10}
    />
  );
}
```

## Ստեղներ

Երբ նվագարկիչը ֆոկուսում է. `Բացատ` կամ `K` — դադար, `←` / `→` — 5 վայրկյան հետ և առաջ, `J` / `L` — `skipSeconds` քայլով, `0`–`9` — անցում հոլովակի 0–90%, `C` — ենթագրեր, `↑` / `↓` — ձայն, `M` — ձայնը միացնել/անջատել, `F` — ամբողջ էկրան, `Esc` — փակել կարգավորումների ընտրացանկը, `Shift+N` / `Shift+P` — ցանկի հաջորդ և նախորդ տեսանյութը։ Ոլորման գծի վրա `Home` / `End` — սկիզբ և վերջ։
