# AnimoLogo

`AnimoLogo` — отдельный компонент Parz UI: логотип-надпись, где каждая буква — маленький огонёк, к центру буквы ярче. Работает сам по себе где угодно и подходит в слот `logo` шапки.

- **появление** — буквы выплывают из размытия, по ним проходит блик;
- **наведение** — волна акцентного цвета;
- **удержание** — буквы сходятся и гаснут, снизу заполняется линия, через `holdDuration` загораются акцентом;
- **отпускание** — плавно расходятся и ненадолго светлеют, без резких вспышек;
- **в покое** — редкое мягкое мерцание.

```tsx
import { ParzMenu, AnimoLogo } from '@carparkteam/parz-ui';

<ParzMenu items={items} desktop={{ logo: <AnimoLogo text="CARPARK" /> }} />

<AnimoLogo text="PARZ" size={22} onClick={() => navigate('/')} onHoldComplete={openAbout} />
```

| Проп | По умолчанию | Что делает |
|---|---|---|
| `text` | `'PARZ'` | Текст логотипа |
| `size` | `13` | Размер букв: px или любая CSS-величина |
| `intro` / `introDelay` | `true` / `150` | Анимация появления при монтировании и её задержка, мс |
| `idle` | `true` | Редкое мерцание в покое |
| `hoverWave` | `true` | Волна при наведении мышью |
| `holdEffect` / `holdDuration` | `true` / `1000` | Эффект удержания и сколько держать, мс |
| `onHoldComplete` | — | Удержали до конца — например, открыть «О приложении» или скрытое меню |
| `onClick` | — | Обычное нажатие или Enter. С ним логотип становится кнопкой |
| `dimColor` / `brightColor` | `#7d7d87` / `#fafafa` | Цвет крайних и центральных букв. Для светлой страницы поменяйте местами |
| `hoverColor` | `#fff` | Цвет при наведении |
| `accent` | `#6ee7a0` | Волна, линия удержания и свечение |
| `spacing` | `0.34` | Расстояние между буквами, em |
| `ariaLabel` | `text` | Подпись для диктора |

Шрифт наследуется от родителя, жирность 700. При системной настройке «уменьшить движение» остаётся только смена цвета.
