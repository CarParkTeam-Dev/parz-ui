# Parz Pager

`ParzPager` — страницы, которые листаются свайпом. Страница едет ровно за пальцем, после броска встаёт на соседнюю пружиной, за краем тянется с сопротивлением. Внутри может быть что угодно: карточки, онбординг, галерея, списки.

- **по кругу**: `loop` — после последней страницы лента едет дальше в ту же сторону к первой, без перемотки назад; без `loop` первая — первая, последняя — последняя, за краем сопротивление;
- **вид**: `effect` — `'slide'`, `'scale'` (соседние меньше и тусклее), `'tilt'` (лёгкий 3D-поворот), `'fade'`; `peek` — сколько px соседних страниц видно по краям;
- **точки и стрелки**: `dots` — активная тянется каплей в том же кадре, что и лента, по точке можно нажать; `arrows` — стеклянные кружки по краям: на компьютере выкатываются каплей при наведении и прячутся, когда курсор уходит, на сенсоре видны всегда; `theme` — для тёмного или светлого фона;
- **автолистание**: `autoplay={3000}` — активная точка заливается слева за время таймера; замирает, пока страницу трогают, наводят или в ней фокус; с `loop` — бесконечно вперёд, без него — до последней и стоп;
- **тени**: лента обрезается только по горизонтали — тени карточек сверху и снизу видны целиком;
- **жест**: вертикальный свайп остаётся прокруткой страницы, горизонтальный листает; бросок — на соседнюю страницу;
- **колесо и тачпад**: горизонтальный жест — одна страница; `wheel={false}` — выключить;
- **onProgress**: дробная позиция каждый кадр — для точек, параллакса или Parz Title Tabs; за краем меньше 0 или больше последней;
- **onRelease**: позиция в момент, когда отпустили палец;
- **клавиатура**: стрелки, Home / End; скрытые страницы недоступны для фокуса;
- **ParzProvider**: пружина из пресета; при `prefers-reduced-motion` — без анимации.

```tsx
import { useState } from 'react';
import { ParzProvider, ParzPager } from '@carparkteam/parz-ui';
import '@carparkteam/parz-ui/style.css';

const [index, setIndex] = useState(0);

<ParzProvider motion="bouncy">
  <ParzPager index={index} onIndexChange={setIndex} onProgress={p => moveDots(p)}>
    <Slide1 />
    <Slide2 />
    <Slide3 />
  </ParzPager>
</ParzProvider>
```

| Проп | По умолчанию | Что делает |
|---|---|---|
| `children` | — | Страницы |
| `index` | — | Текущая страница (управляемый режим) |
| `defaultIndex` | `0` | Начальная страница |
| `onIndexChange` | — | Страница сменилась |
| `onProgress` | — | Дробная позиция каждый кадр |
| `onRelease` | — | Позиция, когда отпустили палец |
| `effect` | `'slide'` | `'slide'`, `'scale'`, `'tilt'`, `'fade'` |
| `pageWidth` | — | Наибольшая ширина страницы, px: в широком контейнере страница по центру, соседи с обеих сторон |
| `peek` | `0` | Сколько px соседних страниц видно |
| `dots` | `false` | Точки под страницами |
| `arrows` | `false` | Стрелки по краям |
| `loop` | `false` | Бесконечная лента: после последней дальше идёт первая; без него края фиксированы |
| `autoplay` | — | Листать само каждые N мс |
| `paused` | `false` | Поставить автолистание на паузу снаружи |
| `theme` | `'dark'` | Цвет точек и стрелок: `'dark'` или `'light'` |
| `labels` | английские | `prev`, `next`, `page` (`'Page {n}'`) |
| `gap` | `12` | Промежуток между страницами, px |
| `wheel` | `true` | Колесо и тачпад |
| `motion` | из `ParzProvider` | `'calm'`, `'bouncy'`, `'snappy'` |
| `ariaLabel` | — | Имя для экранных дикторов |
