# Parz Video

`ParzVideo` — видеоплеер Parz UI. Панель управления — жидкое стекло, которое плавает над видео и мягко прячется, пока вы смотрите. Ничего резкого.

- **перемотка** — полоса течёт на каждом кадре, а не скачет раз в четверть секунды; при наведении она утолщается, проявляется бегунок и подсказка со временем;
- **центр** — как в плеере Apple: стеклянная кнопка «смотреть/пауза», по бокам −10 и +10 (на узком плеере ±10 — в панели); виден вместе с панелью;
- **обложка** — `poster` лежит поверх видео и плавно растворяется при запуске;
- **значок звука** — `audioBadge="Dolby Atmos"` показывает знак Dolby Atmos, `"Spatial Audio"` — иконку объёмного звука, другой текст — значок с волнами;
- **значки** — «смотреть», «пауза» и «смотреть снова», громкость, полный экран перетекают друг в друга;
- **панель** — через `hideDelay` без движения мыши мягко растворяется, на паузе всегда видна;
- **громкость** — ползунок раскрывается при наведении на кнопку звука, ширина перетекает;
- **настройки** — шестерёнка открывает стеклянное меню: качество, скорость, субтитры и повтор. Страницы въезжают сбоку, высота меню перетекает, модальных окон нет;
- **качество** — при смене время и пауза сохраняются, а последний кадр плавно растворяется в новом;
- **главы** — полоса делится на отрезки, название главы видно в подсказке и рядом со временем;
- **кадр при наведении** — над полосой показывается кадр из того места, куда наведён курсор;
- **субтитры** — WebVTT в стиле плеера; когда видна панель, строка мягко приподнимается;
- **±10 секунд** — кнопки перемотки; щелчок по времени показывает, сколько осталось;
- **подсказки** — при паузе, перемотке и смене громкости в центре мягко проявляется значок;
- **ожидание** — до старта, пока набирается буфер, в центральной кнопке бегут точки на тёмном размытом стекле; если видео подгружается во время показа, в центре вращается дуга;
- **телефон** — касание показывает или прячет панель, двойное касание по краю перематывает на 10 секунд; на узком плеере громкость — только кнопкой;
- **правый клик** — своё меню у курсора: знак Parz UI, «by CarPark Team», версия и «О Parz UI» (открывает dev.carpark.am/parz-ui в новой вкладке);
- **меньше движения** — при `prefers-reduced-motion` переходы почти мгновенные.

## Раскладка

Всё над видео — отдельные стеклянные капсулы без рамки, глубину даёт резкая тень снаружи. Появляются и прячутся вместе.

- **сверху слева** — название, пометка качества (4K / HD) и текущая глава;
- **сверху справа** — значок формата звука и громкость: на ПК круглая кнопка звука, дорожка раскрывается при наведении;
- **в центре** — «смотреть/пауза» и −10 / +10, как в плеере Apple;
- **над шкалой справа** — качество, субтитры, скорость и «ещё» (повтор), рядом — картинка в картинке, трансляция и полный экран;
- **внизу** — шкала в своей капсуле: время, полоса, сколько осталось (щелчок — общая длина).

**Узкий плеер (до 460 px, телефон):** сверху слева — картинка в картинке и трансляция, сверху справа — кнопка звука (только mute / unmute), внизу справа — кнопка «…» и правее неё полный экран; в меню «…» с иконками: качество, скорость, субтитры, повтор. На низком плеере название прячется.

```tsx
import { ParzVideo } from '@carparkteam/parz-ui';
import '@carparkteam/parz-ui/style.css';

<ParzVideo src="/video.mp4" poster="/poster.jpg" title="Наш ролик" />

// качество, главы и субтитры
<ParzVideo
  sources={[
    { src: '/video-2160.mp4', label: '2160p' }, // на панели — 4K
    { src: '/video-1080.mp4', label: '1080p' }, // — HD
    { src: '/video-720.mp4', label: '720p' }
  ]}
  chapters={[{ start: 0, title: 'Вступление' }, { start: 42, title: 'Главное' }]}
  tracks={[{ src: '/subs.ru.vtt', label: 'Русский', srclang: 'ru', default: true }]}
/>
```

## Озвучка на нескольких языках

Для сериалов и дубляжа передайте `audio`: каждый язык — своя версия ролика, один файл или свои качества. Переключение сохраняет время и паузу, а кадр растворяется так же, как при смене качества; «Авто» качество работает внутри выбранного языка. В плейлисте выбор зрителя переходит на следующие серии (по `lang`, иначе по подписи). Кнопка стоит на панели рядом с субтитрами; `buttons={{ audio: 'more' }}` переносит её в «Ещё» (на узком плеере она всегда там).

```tsx
<ParzVideo
  audio={[
    { label: 'English', lang: 'en', sources: [{ src: '/e1.en.1080.mp4', label: '1080p' }, { src: '/e1.en.720.mp4', label: '720p' }] },
    { label: 'Русский', lang: 'ru', src: '/e1.ru.mp4' }
  ]}
  defaultAudio="ru"
/>
```

## Запоминание просмотра

С `remember` плеер хранит в браузере самого зрителя (`localStorage`) серию и место, озвучку, субтитры, качество (или «Авто»), скорость и громкость. В следующий раз вместо «смотреть» появляется стеклянная капсула «Продолжить · Серия 2 · 15:12 · Дубляж» и маленькая «Сначала», а на шкале уже отмечено, где остановились. Место сохраняется раз в несколько секунд, на паузе, при смене настроек и при закрытии вкладки — даже если браузер вылетит, потеряется лишь несколько секунд. Самое начало (меньше 10 с) не запоминается; ролик, досмотренный дальше 95%, считается просмотренным, и в плейлисте предлагается следующая серия.

```tsx
<ParzVideo
  playlist={episodes}
  remember="series-42"                  // свой ключ у каждого фильма или сериала
  rememberOptions={{ volume: false }}   // по желанию: что не запоминать
/>
```

Чтобы хранить прогресс на своём сервере (один аккаунт, разные устройства), передайте `initialState` и сохраняйте то, что приходит в `onProgress`:

```tsx
<ParzVideo
  initialState={progressFromServer}       // { i, t, audio, sub, q, rate, … }
  onProgress={state => fetch('/api/progress', { method: 'POST', body: JSON.stringify(state) })}
/>
```

## Плейлист

Передайте `playlist` — плеер играет ролики друг за другом. У каждого ролика свои `src` или `sources`, `title`, `poster`, `chapters`, `tracks` и необязательная `duration` для списка. В центре по краям от −10 / +10 — «предыдущий» и «следующий» (на узком плеере — вместо них); кнопка списка открывает ролики с миниатюрами, текущий отмечен. За несколько секунд до конца появляется карточка «Далее» с кольцом отсчёта: нажмите — следующий ролик начнётся сразу, отмените — ролик просто закончится. При переключении воспроизведение продолжается, а последний кадр растворяется в новом ролике.

```tsx
<ParzVideo
  playlist={[
    { src: '/intro.mp4', title: 'Вступление', poster: '/intro.jpg', duration: 64 },
    { src: '/bay.mp4', title: 'Бухта', poster: '/bay.jpg', duration: 27 }
  ]}
/>
```

Данные можно брать из своего API: превратите каждую запись в `ParzVideoItem`. У каждого ролика остаются свои качества, субтитры и главы; через `index` и `onIndexChange` вы сами управляете, какой ролик идёт (например, чтобы запоминать прогресс).

```tsx
import { useEffect, useState } from 'react';
import { ParzVideo, type ParzVideoItem } from '@carparkteam/parz-ui';

// что отдаёт ваш API — форма любая, здесь пример
type ApiVideo = {
  id: string; name: string; cover: string; length: number;
  files: { url: string; height: number }[];
  subtitles: { url: string; lang: string; name: string }[];
  parts: { at: number; name: string }[];
};

const toItem = (v: ApiVideo): ParzVideoItem => ({
  title: v.name,
  poster: v.cover,
  duration: v.length,
  // у каждого ролика свои качества, субтитры и главы
  sources: v.files.sort((a, b) => b.height - a.height).map(f => ({ src: f.url, label: `${f.height}p` })),
  tracks: v.subtitles.map(s => ({ src: s.url, srclang: s.lang, label: s.name })),
  chapters: v.parts.map(p => ({ start: p.at, title: p.name }))
});

export function Course({ id }: { id: string }) {
  const [items, setItems] = useState<ParzVideoItem[]>([]);
  const [index, setIndex] = useState(0);
  useEffect(() => {
    fetch(`/api/courses/${id}/videos`).then(r => r.json()).then((list: ApiVideo[]) => setItems(list.map(toItem)));
  }, [id]);
  if (!items.length) return null;
  return (
    <ParzVideo
      playlist={items}
      index={index}
      onIndexChange={i => { setIndex(i); /* например, сохранить прогресс: fetch('/api/progress', …) */ }}
      upNextSeconds={10}
    />
  );
}
```

## Клавиши

Когда плеер в фокусе: `Пробел` или `K` — пауза, `←` / `→` — 5 секунд назад и вперёд, `J` / `L` — на шаг `skipSeconds`, `0`–`9` — переход к 0–90% ролика, `C` — субтитры, `↑` / `↓` — громкость, `M` — звук, `F` — полный экран, `Esc` — закрыть меню настроек, `Shift+N` / `Shift+P` — следующий и предыдущий ролик плейлиста. На полосе перемотки `Home` / `End` — в начало и в конец.

| Пропс | По умолчанию | Что делает |
|---|---|---|
| `src` | — | Адрес видео (можно не задавать, если есть `sources`) |
| `sources` | — | Варианты качества: `{ src, label, type?, badge? }[]`. Пометка рядом со шестерёнкой ставится сама по подписи: `2160p` и выше — **4K**, `720p` и выше — **HD**; свою задаёт `badge`, пустая строка — без пометки |
| `defaultQuality` | `'auto'` | Какое качество взять сначала: номер в `sources` или `'auto'` — плеер сам выбирает по своему размеру, плотности экрана и сети (экономия трафика, 2g/3g, скорость) и опускается ниже, если видео подвисает. Выбор вручную отключает автоматику, пункт «Авто» в меню включает обратно |
| `chapters` | — | Главы: `{ start, title }[]`, `start` в секундах |
| `audio` | — | Озвучки: `{ label, lang?, src?, sources? }[]` — у каждой свой файл или свои качества (тогда `src` и `sources` не нужны) |
| `defaultAudio` | первая | С какой озвучки начать: номер или `lang` |
| `onAudioChange` | — | `(index, audio) => void` |
| `buttons` | все на панели | Какие кнопки настроек убрать в «Ещё»: `{ audio?, subtitles?, speed?: 'bar' \| 'more' }`. Качество и плейлист всегда на панели, повтор всегда в «Ещё»; на панели не больше 5 кнопок, лишние уходят в «Ещё»; на узком плеере всё в «Ещё». «Картинка в картинке» и трансляция — отдельно |
| `showShare` / `shareUrl` | `true` / адрес страницы | «Поделиться» в «Ещё»: скопировать ссылку и «Другое…» — системное окно браузера (показывается, только если оно есть) |
| `remember` | — | Ключ, под которым запоминается просмотр и настройки зрителя в его браузере |
| `rememberOptions` | всё | Что не запоминать: `{ position?, audio?, subtitles?, quality?, speed?, volume?: false }` |
| `initialState` / `onProgress` | — | Своё хранилище: начальное состояние вместо `localStorage` и вызов при каждом сохранении |
| `tracks` | — | Субтитры WebVTT: `{ src, label, srclang, default? }[]`. Изначально выключены; `default` — дорожка, которую включает клавиша C. С чужого домена нужен CORS |
| `previews` | `true` | Кадр над полосой при наведении (грузит видео второй раз, только нужные кадры) |
| `poster` | — | Обложка до запуска; мягко проявляется, когда картинка загрузилась, плавно растворяется, когда видео пошло, и возвращается, когда оно закончилось (если нет `loop`) |
| `title` | — | Заголовок вверху; прячется вместе с панелью |
| `audioBadge` | — | Значок формата звука справа сверху; когда интерфейс прячется, плавно отъезжает в угол, держится ещё 3 с и растворяется. `'Dolby Atmos'` — знак Dolby Atmos, `'Spatial Audio'` — иконка объёмного звука, другой текст (`'5.1'`…) — с волнами |
| `autoPlay` / `muted` / `loop` | `false` | Как у `<video>`. Браузеры запускают видео сами только без звука |
| `aspectRatio` | `'16 / 9'` | Соотношение сторон |
| `accent` | `#6ee7a0` | Цвет полосы перемотки, громкости и большой кнопки |
| `motion` | `'liquid'` | Стиль анимаций: `'liquid'` — элементы появляются и прячутся как капли, на упругой пружине (капсулы вырастают из своего края, −10/+10 отделяются от центральной кнопки, меню вырастает из кнопки); `'fade'` — спокойное проявление и растворение |
| `radius` | `18` | Скругление, px (во весь экран — без скругления) |
| `showSkip` / `skipSeconds` | `true` / `10` | Кнопки перемотки назад и вперёд и их шаг |
| `showVolume` | `true` | Кнопка и ползунок громкости |
| `showSettings` | `true` | Кнопки качества, субтитров, скорости и «ещё» (повтор) |
| `showCast` | `true` | Трансляция (AirPlay, Chromecast через Remote Playback) — кнопка появляется, только если браузер видит устройство |
| `showFullscreen` | `true` | Кнопка полного экрана (двойной щелчок по видео — тоже) |
| `showPip` | `false` | «Картинка в картинке», если браузер умеет |
| `speeds` | `[0.25, 0.5, 0.75, 1, 1.25, 1.5, 1.75, 2]` | Скорости в меню |
| `hideDelay` | `2600` | Через сколько мс без движения прятать панель |
| `labels` | английские | Подписи кнопок для экранных дикторов: `play`, `pause`, `replay`, `mute`, `unmute`, `volume`, `seek`, `speed`, `fullscreen`, `exitFullscreen`, `pip`, `player`, `normal`, `settings`, `quality`, `subtitles`, `off`, `loop`, `back`, `forward` (`{n}` — шаг), `remaining`, `more`, `cast`, `on`, `casting`, `castBack`, `pipActive`, `pipBack`, `auto`, `resume`, `startOver`, `episode`, `audioTrack`, `share`, `copyLink`, `linkCopied`, `shareOther`, `playlist`, `previous`, `next`, `upNext`, `playNow`, `cancel`, `nowPlaying` |
| `onPlay` / `onPause` / `onEnded` | — | События воспроизведения |
| `onTimeUpdate` | — | `(time, duration) => void` |
| `onQualityChange` | — | `(index, source) => void` |
| `playlist` | — | Ролики подряд: `{ src?, sources?, audio?, title?, poster?, chapters?, tracks?, audioBadge?, duration? }[]`. Поля текущего ролика заменяют `src`, `sources`, `title`, `poster`, `chapters` и `tracks` |
| `index` / `defaultIndex` | `0` | Текущий ролик (управляемый / начальный) |
| `onIndexChange` | — | `(index, item) => void` — ролик сменился |
| `autoAdvance` | `true` | Включать следующий ролик, когда текущий закончился |
| `upNextSeconds` | `8` | За сколько секунд до конца показывать карточку «Далее»; `0` — не показывать |
| `className` / `style` | — | На корневой элемент |

## CSS-переменные

`--pz-vd-accent` (акцент), `--pz-vd-r` (скругление), `--pz-vd-glass` (фон панели), `--pz-vd-line` (кромка панели), `--pz-vd-fg` (цвет значков и текста).

```css
.trailer { --pz-vd-accent: #7aa7ff; --pz-vd-glass: rgba(10, 10, 20, .6); }
```
