# Parz Badge

`ParzBadge` — метка или счётчик Parz UI. Появляется каплей, при смене числа цифры перекатываются, а ширина перетекает под новое значение — ничего не прыгает. Можно поставить отдельно или в угол кнопки, аватара, иконки.

- **появление** — раздувается из маленькой капли, мягко сплющивается и успокаивается;
- **смена числа** — старое число уезжает, новое въезжает (вверх, когда растёт, вниз — когда уменьшается), ширина перетекает;
- **исчезновение** — когда `count` становится 0 (или бейдж убрали), он стягивается в каплю и тает;
- **пульс** — мягкое кольцо расходится и тает: удобно для точки «в сети» или «идёт запись»;
- **меньше движения** — при `prefers-reduced-motion` всё меняется без движения.

Текст и цифры стоят ровно по центру по сетке пикселей во всех размерах.

```tsx
import { ParzBadge, ParzButton } from '@carparkteam/parz-ui';
import '@carparkteam/parz-ui/style.css';

<ParzBadge label="Новое" />
<ParzBadge label="Beta" variant="soft" color="#7aa7ff" />

// в углу кнопки
<ParzBadge count={unread} ariaLabel={`Новых сообщений: ${unread}`}>
  <ParzButton icon="ms:notifications" iconOnly ariaLabel="Уведомления" />
</ParzBadge>

// точка «в сети»
<ParzBadge dot pulse color="#38c172" ariaLabel="В сети">
  <Avatar />
</ParzBadge>
```

| Пропс | По умолчанию | Что делает |
|---|---|---|
| `label` | — | Текст: «Новое», «Beta»… |
| `count` | — | Число. Больше `max` — показывается `max+`; `0` прячет бейдж |
| `max` | `99` | Максимум для `count` |
| `showZero` | `false` | Показывать `0`, а не прятать |
| `dot` | `false` | Точка без текста |
| `pulse` | `false` | Мягкое пульсирующее кольцо |
| `icon` | — | Иконка перед текстом: встроенная, `'ms:имя'`, `'mi:имя'` или свой узел |
| `variant` | `'solid'` | `'solid'`, `'soft'`, `'outline'` или `'glass'` |
| `size` | `'md'` | `'sm'` (15 px), `'md'` (20 px), `'lg'` (24 px) |
| `color` | `#ff4d5e` | Основной цвет |
| `textColor` | — | Цвет текста |
| `children` | — | Элемент, на который садится бейдж. Без него бейдж стоит в строке |
| `placement` | `'top-end'` | Угол: `'top-end'`, `'top-start'`, `'bottom-end'`, `'bottom-start'` |
| `ariaLabel` | — | Текст для экранных дикторов, например «3 новых сообщения» |
| `className` / `style` | — | На бейдж (или на обёртку, если есть `children`) |

## CSS-переменные

`--pz-bd-color` (основной цвет), `--pz-bd-fg` (текст), `--pz-bd-ring` (тонкая обводка вокруг бейджа в углу — задайте цвет вашего фона).

```css
.toolbar { --pz-bd-ring: #101014; }
```
