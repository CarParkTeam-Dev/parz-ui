# Parz Badge

`ParzBadge`-ը Parz UI-ի պիտակ կամ հաշվիչ է։ Հայտնվում է կաթիլի պես, թիվը փոխվելիս թվանշանները գլորվում են, իսկ լայնությունը սահուն հարմարվում է նոր արժեքին՝ ոչինչ չի ցատկում։ Կարելի է դնել առանձին կամ կոճակի, ավատարի, պատկերակի անկյունում։

- **հայտնվել** — ուռչում է փոքր կաթիլից, մեղմ տափակում և հանդարտվում;
- **թվի փոփոխություն** — հին թիվը դուրս է սահում, նորը ներս է մտնում (վեր՝ երբ աճում է, վար՝ երբ նվազում է), լայնությունը սահուն փոխվում է;
- **անհետանալ** — երբ `count`-ը դառնում է 0 (կամ պիտակը հեռացվում է), այն սեղմվում է կաթիլի և հալվում;
- **զարկերակ** — մեղմ օղակը տարածվում և հալվում է. հարմար է «առցանց» կամ «ձայնագրում» կետի համար;
- **քիչ շարժում** — `prefers-reduced-motion`-ի դեպքում ամեն ինչ փոխվում է առանց շարժման։

Տեքստը և թվանշանները բոլոր չափերում ճիշտ կենտրոնում են՝ պիքսելային ցանցով։

```tsx
import { ParzBadge, ParzButton } from '@carparkteam/parz-ui';
import '@carparkteam/parz-ui/style.css';

<ParzBadge label="Նոր" />
<ParzBadge label="Beta" variant="soft" color="#7aa7ff" />

// կոճակի անկյունում
<ParzBadge count={unread} ariaLabel={`Նոր հաղորդագրություններ՝ ${unread}`}>
  <ParzButton icon="ms:notifications" iconOnly ariaLabel="Ծանուցումներ" />
</ParzBadge>

// «առցանց» կետ
<ParzBadge dot pulse color="#38c172" ariaLabel="Առցանց">
  <Avatar />
</ParzBadge>
```

| Prop | Լռելյայն | Ինչ է անում |
|---|---|---|
| `label` | — | Տեքստ՝ «Նոր», «Beta»… |
| `count` | — | Թիվ։ `max`-ից մեծ լինելու դեպքում ցույց է տրվում `max+`; `0`-ն թաքցնում է պիտակը |
| `max` | `99` | Առավելագույնը `count`-ի համար |
| `showZero` | `false` | Ցույց տալ `0`-ն, ոչ թե թաքցնել |
| `dot` | `false` | Կետ առանց տեքստի |
| `pulse` | `false` | Մեղմ զարկերակող օղակ |
| `icon` | — | Պատկերակ տեքստից առաջ՝ ներկառուցված, `'ms:անուն'`, `'mi:անուն'` կամ ձեր սեփական հանգույցը |
| `variant` | `'solid'` | `'solid'`, `'soft'`, `'outline'` կամ `'glass'` |
| `size` | `'md'` | `'sm'` (15 px), `'md'` (20 px), `'lg'` (24 px) |
| `color` | `#ff4d5e` | Հիմնական գույն |
| `textColor` | — | Տեքստի գույն |
| `children` | — | Տարրը, որի վրա նստում է պիտակը։ Առանց դրա պիտակը տողում է |
| `placement` | `'top-end'` | Անկյուն՝ `'top-end'`, `'top-start'`, `'bottom-end'`, `'bottom-start'` |
| `ariaLabel` | — | Տեքստ էկրանի ընթերցիչների համար, օրինակ՝ «3 նոր հաղորդագրություն» |
| `className` / `style` | — | Պիտակի վրա (կամ փաթաթողի վրա, եթե կան `children`) |

## CSS փոփոխականներ

`--pz-bd-color` (հիմնական գույն), `--pz-bd-fg` (տեքստ), `--pz-bd-ring` (բարակ եզրագիծ անկյունի պիտակի շուրջ. նշեք ձեր ֆոնի գույնը)։

```css
.toolbar { --pz-bd-ring: #101014; }
```
