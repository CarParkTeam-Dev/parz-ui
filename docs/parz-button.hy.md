# Parz Button

`ParzButton`-ը Parz UI-ի կոճակ է հեղուկ անիմացիայով։ Սեղմելիս այն մեղմ սեղմվում է և զսպանակով վերադառնում, իսկ հպման կետից կաթիլ է տարածվում։ Ոչինչ չի ցնցվում։

- **սեղմում** — կոճակը մեղմ փոքրանում է և բաց թողնելիս զսպանակում;
- **կաթիլ** — ալիքը տարածվում է հպման կետից (ստեղնաշարով՝ կենտրոնից);
- **պահում** — կոճակը մնում է սեղմված, կաթիլը մեծանում է, պիտակի տակ դանդաղ գրադիենտ է հոսում; բաց թողնելիս ամեն ինչ սահուն հալվում է;
- **բովանդակության փոփոխություն** — երբ պիտակը կամ պատկերակը փոխվում է, հինը լուծվում է, նորը հայտնվում, իսկ լայնությունը սահուն անցնում է նորին;
- **բեռնում** — պիտակը սահուն անհետանում է, նրա տեղում «կենդանի» կետեր են, լայնությունը չի փոխվում; դրվում է `aria-busy`;
- **սավառնում** — փոխվում է միայն գույնը, կոճակը չի բարձրանում;
- **ստեղնաշար** — Tab՝ ֆոկուսի համար (երևում է օղակ), Enter կամ Բացատ՝ սեղմելու համար;
- **քիչ շարժում** — `prefers-reduced-motion`-ի դեպքում սեղմում և կաթիլ չկան, կետերը պարզապես թարթում են։

Ներսում իսկական `<button>` է, իսկ `href`-ի դեպքում՝ `<a>` հղում, ուստի ձևերը, հղումները և էկրանի ընթերցիչները աշխատում են սովորականի պես։

```tsx
import { ParzButton } from '@carparkteam/parz-ui';
import '@carparkteam/parz-ui/style.css';

<ParzButton onClick={save} iconEnd="ms:arrow_forward">Շարունակել</ParzButton>

<ParzButton variant="soft" loading={saving} loadingText="Պահպանում ենք">Պահպանել</ParzButton>

<ParzButton variant="glass" icon="ms:favorite" iconOnly ariaLabel="Ընտրյալներում" />

<ParzButton variant="outline" href="/docs">Փաստաթղթեր</ParzButton>
```

| Prop | Լռելյայն | Ինչ է անում |
|---|---|---|
| `children` | — | Պիտակ |
| `variant` | `'solid'` | `'solid'`, `'soft'`, `'outline'`, `'ghost'` կամ `'glass'` |
| `size` | `'md'` | `'sm'` (34 px), `'md'` (42 px), `'lg'` (52 px) |
| `shape` | `'pill'` | `'pill'`, `'rounded'` կամ `'square'` |
| `icon` / `iconEnd` | — | Պատկերակ պիտակից առաջ / հետո՝ ներկառուցված, `'ms:անուն'`, `'mi:անուն'` կամ ձեր սեփական հանգույցը |
| `iconOnly` | `false` | Քառակուսի կոճակ միայն պատկերակով։ Նշեք նաև `ariaLabel` |
| `ariaLabel` | — | Անուն էկրանի ընթերցիչների համար |
| `loading` | `false` | Պիտակի փոխարեն կենդանի կետեր; սեղմել հնարավոր չէ |
| `loadingText` | — | Տեքստ կետերի կողքին բեռնման ժամանակ |
| `disabled` | `false` | Խամրած է, սեղմել հնարավոր չէ |
| `fullWidth` | `false` | Ամբողջ լայնությամբ |
| `href` / `target` / `rel` | — | Ստեղծում է `<a>` հղում |
| `type` | `'button'` | `<button>`-ի `type`-ը |
| `onClick` | — | Սեղմման մշակիչ; չի կանչվում `disabled`-ի և `loading`-ի ժամանակ |
| `onLongPress` | — | Սեղմում և պահում՝ պահելիս պիտակի տակ գրադիենտ է հոսում; երբ կաթիլը լցնում է կոճակը, կանչվում է սա `onClick`-ի փոխարեն |
| `longPressDelay` | `600` | Որքան պահել `onLongPress`-ի համար, մվ |
| `accent` | `#6ee7a0` | Հիմնական գույն |
| `textColor` | — | Տեքստի և պատկերակների գույն |
| `ripple` | `true` | Կաթիլ սեղմման կետից |
| `id` / `name` / `value` | — | Փոխանցվում են տարրին |
| `className` / `style` | — | Արմատային տարրի վրա |

## CSS փոփոխականներ

Նշվում են կոճակի կամ ցանկացած ծնողի վրա՝ `--pz-btn-accent` (հիմնական գույն), `--pz-btn-fg` (տեքստի գույն), `--ltb-icon` (պատկերակի չափ), `--pz-btn-shade` — որքան մգացնել `soft`, `outline` և `ghost` տեքստը (լռելյայն `0%`; բաց էջում դրեք մոտ `45%`, որպեսզի բաց շեշտը ընթեռնելի լինի)։

```css
.checkout { --pz-btn-accent: #ff8a3d; }
.light-page { --pz-btn-shade: 45%; }
```
