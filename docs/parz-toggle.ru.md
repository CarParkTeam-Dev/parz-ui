# Parz Toggle

`ParzToggle` — переключатель Parz UI с жидким бегунком. При переключении бегунок тянется туда, куда едет, сплющивается на месте и успокаивается с лёгким перелётом — как в Parz Menu. Ничего резкого.

- **нажатие или клик** — переключается с жидкой анимацией;
- **удержание** — бегунок мягко вытягивается, как капля;
- **перетаскивание** — тяните бегунок пальцем или мышью; отпустите за серединой — переключится;
- **клавиатура** — Tab ставит фокус (появляется заметное кольцо), Пробел или Enter переключают;
- **меньше движения** — при `prefers-reduced-motion` просто скользит, без сплющивания.

Внутри — настоящий `<input type="checkbox" role="switch">`, поэтому формы, `name`, экранные дикторы и фокус работают как обычно.

```tsx
import { useState } from 'react';
import { ParzToggle } from '@parz/ui';
import '@parz/ui/style.css';

const [on, setOn] = useState(true);

<ParzToggle checked={on} onChange={setOn} label="Wi-Fi" />

// неуправляемый, без видимой подписи
<ParzToggle defaultChecked ariaLabel="Тёмная тема" size="lg" accent="#7aa7ff" />
```

| Проп | По умолчанию | Что делает |
|---|---|---|
| `checked` | — | Состояние (управляемый режим) |
| `defaultChecked` | `false` | Начальное состояние (неуправляемый режим) |
| `onChange` | — | `(checked: boolean) => void` — при клике, с клавиатуры или перетаскиванием |
| `label` | — | Текст или элемент рядом с тумблером |
| `labelPosition` | `'end'` | `'end'` — подпись справа, `'start'` — слева |
| `ariaLabel` | — | Имя для экранных дикторов, если нет видимой `label` |
| `disabled` | `false` | Отключён, приглушён, не получает фокус |
| `size` | `'md'` | `'sm'` (16 px), `'md'` (20 px), `'lg'` (28 px) или высота дорожки в px |
| `accent` | `#6ee7a0` | Цвет включённой дорожки |
| `trackColor` | `#2a2a30` | Цвет выключенной дорожки. На светлой странице — например, `#d9dae1` |
| `thumbColor` | `#fff` | Цвет бегунка |
| `draggable` | `true` | Можно ли тянуть бегунок |
| `cooldown` | `0` | Минимальная пауза между переключениями, мс. Слишком частая попытка отклоняется |
| `canChange` | — | `(next) => boolean` — своя проверка; `false` отклоняет переключение |
| `onReject` | — | `(next) => void` — вызывается, когда попытку отклонили |
| `rejectColor` | `#ff5c5c` | Цвет дорожки при отказе |
| `name` / `id` | — | Передаются во внутренний чекбокс |
| `className` / `style` | — | На корневой `<label>` |

## Состояние отказа

Защита от частых вкл/выкл (например, настройка, которая ходит на сервер): задайте `cooldown`. Если переключить снова слишком рано, тумблер не изменится — на секунду дорожка станет красной, бегунок коротко вздрогнет, и всё спокойно вернётся. То же самое — когда `canChange` вернул `false`.

```tsx
<ParzToggle checked={on} onChange={setOn} label="Уведомления"
  cooldown={1500} onReject={() => toast('Слишком часто — подождите')} />
```

## CSS-переменные

Цвета можно задать и из CSS — на самом тумблере или любом родителе: `--pz-tg-accent`, `--pz-tg-track`, `--pz-tg-knob`, `--pz-tg-reject`.

```css
.settings { --pz-tg-accent: #ff8a3d; }
```
