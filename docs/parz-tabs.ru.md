# Parz Tabs

`ParzTabs` — сегментированный переключатель Parz UI. Плашка выбора не прыгает, а перетекает к новому пункту: передний край уходит первым, хвост догоняет, и на миг плашка вытягивается каплей — как в Parz Menu.

- **клик или касание** — выбирает пункт;
- **клавиатура** — Tab ставит фокус на выбранный пункт, стрелки и Home / End переключают (пропуская недоступные);
- **перенос** — если пункты не помещаются, они переносятся на новую строку, плашка плавно переезжает и туда;
- **меньше движения** — при `prefers-reduced-motion` плашка переставляется без анимации.

Внутри — `role="radiogroup"` с кнопками `role="radio"`, поэтому экранные дикторы читают его как выбор одного из нескольких.

```tsx
import { useState } from 'react';
import { ParzTabs } from '@carparkteam/parz-ui';
import '@carparkteam/parz-ui/style.css';

const [tab, setTab] = useState('week');

<ParzTabs
  options={[
    { value: 'day', label: 'День' },
    { value: 'week', label: 'Неделя' },
    { value: 'month', label: 'Месяц' }
  ]}
  value={tab}
  onChange={setTab}
  ariaLabel="Период"
/>
```

| Проп | По умолчанию | Что делает |
|---|---|---|
| `options` | — | `{ value, label?, icon?, badge?, badgeColor?, ariaLabel?, disabled? }[]` — пункты; `badge` — число, короткий текст или `'dot'`, `badgePulse` — мягкий пульс |
| `value` | — | Выбранное значение (управляемый режим) |
| `defaultValue` | первый доступный | Начальное значение (неуправляемый режим) |
| `onChange` | — | `(value) => void` |
| `ariaLabel` | — | Имя группы для экранных дикторов |
| `size` | `'md'` | `'sm'`, `'md'` или `'lg'` |
| `fullWidth` | `false` | Растянуть на всю ширину, пункты поровну |
| `overflow` | `'wrap'` | Если пункты не помещаются: `'wrap'` — перенос на новую строку, `'more'` — лишние прячутся в «•••» с меню, `'scroll'` — прокрутка по горизонтали |
| `fadeEdges` | `true` | Для `'scroll'`: затенять края, за которыми есть ещё пункты |
| `scrollButtons` | `false` | Для `'scroll'`: маленькие стрелки по краям. С ними выбранный пункт не прокручивается к центру сам |
| `badgePlacement` | `'inline'` | Где бейджи: `'inline'` — рядом с подписью, `'corner'` — в правом верхнем углу пункта, ширину не меняет |
| `moreIcon` | `'more'` | Иконка кнопки с остальными пунктами — встроенная, `'ms:имя'` или свой элемент |
| `moreLabel` | `'More'` | Подпись «•••» для экранных дикторов |
| `disabled` | `false` | Отключить весь переключатель |
| `background` | `#1c1c21` | Фон дорожки |
| `pillColor` | `#fff` | Цвет плашки |
| `activeColor` | `#000` | Текст выбранного пункта |
| `color` | `#9a9aa3` | Текст остальных пунктов |
| `id` / `className` / `style` | — | На корневой элемент |

## Когда пункты не помещаются

- **`overflow="more"`** — сколько влезает, остаётся в ряду, остальное уходит в «•••». На кнопке — нейтральный счётчик спрятанных пунктов и красная точка, если среди них есть бейджи. Нажали «•••» — плашка перетекает к ней и открывается меню; выбрали пункт из меню — плашка остаётся на «•••».
- **`overflow="scroll"`** — пункты листаются пальцем или колесом, края мягко затеняются (`fadeEdges={false}` — без затенения). Выбранный пункт сам выезжает к центру; с `scrollButtons` по краям появляются стрелки, а авто-прокрутки нет. Если поменять размер, ширину или набор пунктов, выбранный пункт всё равно не останется за краем.

```tsx
<ParzTabs options={opts} value={tab} onChange={setTab} overflow="more" moreLabel="Ещё" />
<ParzTabs options={opts} value={tab} onChange={setTab} overflow="scroll" scrollButtons />
```

## CSS-переменные

На самом переключателе или любом родителе: `--pz-tabs-bg`, `--pz-tabs-pill`, `--pz-tabs-on`, `--pz-tabs-fg`, `--pz-tabs-sh` (тень плашки), `--pz-tabs-menu-bg`, `--pz-tabs-menu-fg`, `--pz-tabs-ring` (кольцо фокуса).
