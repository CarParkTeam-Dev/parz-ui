# Parz Avatar

`ParzAvatar`-ը Parz UI-ի ավատարն է։ Ցույց է տալիս լուսանկար, սկզբնատառեր կամ պատկերակ։ Լուսանկարը հայտնվում է թեթև մշուշից, իսկ բեռնվելու ընթացքում սկզբնատառերի վրայով մեղմ փայլ է անցնում։ Եթե լուսանկարը չբեռնվի, մնում են սկզբնատառերը։ Կարգավիճակի կետը հայտնվում է զսպանակով։ «Պատմությունների» օղակը կարող է լինել վառ կամ մոխրագույն («դիտված»)։

`ParzAvatarGroup`-ը ավատարները դնում է շարքով՝ իրար վրա։ Ավելորդները ծալվում են «+N»-ի մեջ, սավառնելիս շարքը բացվում է, և հայտնվում են անունները։

- **գույնը՝ ըստ անվան**. նույն անունը միշտ ստանում է նույն ֆոնը;
- **կարգավիճակ**. `online`՝ զարկով, `away` (մահիկ), `busy` (գիծ), `offline` (օղակ);
- **օղակ**. `ring`, `ring="seen"` կամ սեփական գրադիենտ; գրադիենտը հոսում է շրջանով (`ringSpin={false}`՝ անշարժ);
- **հաշվիչ**. `count`-ը անկյունում դնում է նշան (ParzBadge);
- **կոճակ կամ հղում**. `onClick` / `href`; սավառնելիս ավատարը մեծանում է զսպանակով;
- **ParzProvider**. զսպանակները հետևում են `calm` / `bouncy` / `snappy` ընդհանուր նախադրվածքին;
- **քիչ շարժում**. `prefers-reduced-motion`-ի դեպքում ամեն ինչ փոխվում է առանց անիմացիայի, զարկը դառնում է հանգիստ թարթում։

```tsx
import { ParzProvider, ParzAvatar, ParzAvatarGroup } from '@carparkteam/parz-ui';
import '@carparkteam/parz-ui/style.css';

<ParzProvider motion="bouncy">
  <ParzAvatar src={user.photo} name="Անի Պետրոսյան" size="lg" status="online" statusLabel="ցանցում" />

  <ParzAvatarGroup max={4} onMoreClick={showAll} ariaLabel="Մասնակիցներ">
    {team.map(u => <ParzAvatar key={u.id} src={u.photo} name={u.name} />)}
  </ParzAvatarGroup>
</ParzProvider>
```

## Ավատարի փոխում

`editable`-ի դեպքում ավատարին սեղմելը բացում է ընտրության պատուհան՝ սկզբնատառեր, պատրաստի նկարներ և «Վերբեռնել լուսանկար» կոճակ։ Ավատարի վրա սավառնելիս հայտնվում է տեսախցիկի պատկերակ։

```tsx
<ParzAvatar
  src={user.photo}
  name={user.name}
  size="xl"
  editable
  onUpload={file => api.uploadAvatar(file)} // Promise<string>՝ պատրաստի լուսանկարի հասցեն
  onUploadError={() => toast('Չհաջողվեց վերբեռնել լուսանկարը')}
  onChange={v => save(v)}
/>
```

Քանի դեռ `onUpload`-ն աշխատում է, ընտրված լուսանկարն արդեն ավատարում է՝ մշուշոտ, և դրա վրայով կետեր են վազում։ Երբ հասցեն գա, հստակ լուսանկարը կհայտնվի նախադիտման տակից։

| Հատկություն | Լռելյայն | Ինչ է անում |
|---|---|---|
| `editable` | `false` | Միացնում է ընտրության պատուհանը |
| `presets` | `PARZ_AVATAR_PRESETS` | Պատրաստի նկարները պատուհանում, հասցեների զանգված |
| `onChange` | — | `{ kind: 'preset', src }`, `{ kind: 'initials' }` կամ `{ kind: 'upload', file, src }` |
| `onUpload` | — | `(file) => Promise<string> \| string`՝ վերբեռնել ֆայլը և վերադարձնել հասցեն |
| `onUploadError` | — | `(error, file)`՝ վերբեռնումը չհաջողվեց, ավատարն արդեն վերադարձել է նախկին տեսքին |
| `value` | — | Կառավարվող ռեժիմ. տողը՝ լուսանկար, `null`՝ սկզբնատառեր։ Ավատարը ցույց է տալիս միայն `value`-ն, ընտրությունը միայն կանչում է `onChange` |
| `accept` | `'image/*'` | Որ ֆայլերը կարելի է ընտրել |
| `labels` | անգլերեն | `title`, `initials`, `upload`, `uploading`, `edit`, `preset` (`'Avatar {n}'`) |

Առանց `value`-ի ավատարը փոխվում է ինքն իրեն՝ ընտրությունից անմիջապես հետո, իսկ դրսից եկած նոր `src`-ն չեղարկում է ընտրությունը։

Առանց `onUpload`-ի լուսանկարը ցույց է տրվում անմիջապես ֆայլից՝ ժամանակավոր `blob:` հասցեով։ Այն աշխատում է, քանի դեռ ավատարը էջում է, և ազատվում է, երբ լուսանկարը փոխվում է կամ ավատարը հեռացվում։ Նման հասցեն սերվերում պահելն անիմաստ է. իրական վերբեռնման համար փոխանցեք `onUpload`։

`ref`-ը ցույց է տալիս հենց ավատարը (կոճակ, հղում կամ `span`), օրինակ՝ դրա վրա ֆոկուս դնելու համար։
