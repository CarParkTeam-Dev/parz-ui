# Parz Days

`ParzDays` — лента дней Parz UI. Карточка выбора стоит на месте, а дни едут под ней, как колесо. Ленту можно тянуть пальцем или мышью, листать тачпадом и нажимать на день. После отпускания она летит по инерции и пружинит на ближайшую дату. На скорости карточка чуть вытягивается и сплющивается, дни к краям гаснут.

- **бесконечная лента**: прошлое и будущее без ограничений, или только между `min` и `max`; за границей лента тянется с сопротивлением;
- **недоступные дни**: `isDisabled`; лента на них не останавливается;
- **метки**: точка под числом, своего цвета для каждого дня;
- **язык**: дни недели и месяц через `Intl` (`locale`);
- **клавиатура**: ← → по дням, PageUp / PageDown по неделям, Home — сегодня;
- **ParzProvider**: первый компонент, который понимает общий пресет движения;
- **меньше движения**: при `prefers-reduced-motion` лента встаёт на день сразу.

```tsx
import { useState } from 'react';
import { ParzProvider, ParzDays } from '@carparkteam/parz-ui';
import '@carparkteam/parz-ui/style.css';

const [day, setDay] = useState(new Date());

<ParzProvider motion="bouncy">
  <ParzDays value={day} onChange={setDay} showMonth todayLabel="Сегодня" marks={d => d.getDate() % 5 === 0} />
</ParzProvider>
```

| Проп | По умолчанию | Что делает |
|---|---|---|
| `value` | — | Выбранный день (управляемый режим) |
| `defaultValue` | сегодня | Начальный день (неуправляемый режим) |
| `onChange` | — | `(date: Date, iso: string) => void`; `iso` — `'YYYY-MM-DD'` по местному времени |
| `name` | — | Имя поля формы: дата уйдёт с формой как `'YYYY-MM-DD'` |
| `min` / `max` | — | Границы ленты |
| `isDisabled` | — | `(date) => boolean` — недоступные дни |
| `disabledDates` | — | Отдельные недоступные даты, `Date[]` |
| `marks` | — | `(date) => boolean \| string` — точка под числом, строка — её цвет |
| `locale` | язык браузера | Язык подписей |
| `weekday` | `'narrow'` | `'narrow'` — одна буква, `'short'` — сокращение |
| `showMonth` | `false` | Месяц и год над лентой, перекатываются при смене |
| `picker` | — | Выбор месяца и года по нажатию на месяц: `'wheels'` — над днями выезжают ленты годов и месяцев, выбранные уровни сжимаются; `'compact'` — мини-окно с месяцами и полем года |
| `pickerYear` | `true` | В выборе можно листать годы; `false` — только месяцы текущего года |
| `showTime` | `false` | Кнопка времени рядом с месяцем; в мини-окне барабаны часов и минут, как в iOS. `onChange` отдаёт `'YYYY-MM-DDTHH:mm'` |
| `minuteStep` | `5` | Шаг минут в барабане |
| `todayLabel` | — | Подпись кнопки «Сегодня»; кнопка появляется, когда выбран другой день |
| `size` | `'md'` | `'sm'`, `'md'`, `'lg'` |
| `theme` | `'light'` | `'light'` или `'dark'` |
| `motion` | из `ParzProvider` | `'calm'`, `'bouncy'`, `'snappy'` |
| `cardColor`, `color`, `weekdayColor`, `markColor` | — | Цвета |
| `highlightToday` | `true` | Выделять сегодняшний день цветом |
| `todayColor` | зелёный | Цвет числа сегодняшнего дня |
| `highlightSunday` | `true` | Выделять название воскресенья цветом |
| `sundayColor` | красный | Цвет названия воскресенья |
| `highlightCurrent` | `true` | В выборе выделять текущий год и месяц |
| `currentColor` | как `todayColor` (зелёный) | Их цвет |
| `ariaLabel` | — | Имя для экранных дикторов |
| `disabled` | `false` | Лента не двигается |


## Границы дат

Какие бы `min` / `max` ни передали, лента не уходит раньше **1 января 1900** и позже **31 декабря через 100 лет** от сегодня (`PARZ_DAYS_MIN_YEAR`, `PARZ_DAYS_MAX_YEARS_AHEAD`). Если границы зажаты, в консоли будет предупреждение.

## Дата для API

```tsx
import { ParzDays, toISODate } from '@carparkteam/parz-ui';

<ParzDays onChange={(date, iso) => fetch(`/api/slots?date=${iso}`)} />

// или в обычной форме
<form action="/book"><ParzDays name="date" /><button>Забронировать</button></form>
```

## ParzProvider

Общий пресет движения для новых компонентов. Поддерживается начиная с **Parz Days**; компоненты, вышедшие раньше, пока его не читают.

| Пресет | Характер |
|---|---|
| `calm` | мягко, без перелёта |
| `bouncy` | живая пружина с лёгким перелётом (по умолчанию) |
| `snappy` | быстро и чётко |

Проп `motion` у компонента важнее провайдера.
