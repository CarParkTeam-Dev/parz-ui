# Parz Toggle

`ParzToggle`-ը Parz UI-ի անջատիչն է՝ հեղուկ սահնակով։ Փոխարկելիս սահնակը ձգվում է դեպի իր ուղղությունը, տեղ հասնելով տափակում է և հանգստանում թեթև անցումով՝ ինչպես Parz Menu-ում։ Ոչինչ կտրուկ չէ։

- **սեղմում կամ կտտոց** — փոխարկվում է հեղուկ անիմացիայով;
- **պահում** — սահնակը մեղմ ձգվում է կաթիլի պես;
- **քաշում** — քաշեք սահնակը մատով կամ մկնիկով, մեջտեղից այն կողմ բաց թողնելիս կփոխարկվի;
- **ստեղնաշար** — Tab-ը տալիս է ֆոկուս (երևում է օղակ), Space կամ Enter՝ փոխարկում;
- **քիչ շարժում** — `prefers-reduced-motion`-ի դեպքում պարզապես սահում է՝ առանց տափակելու։

Ներսում իսկական `<input type="checkbox" role="switch">` է, ուստի ձևերը, `name`-ը, էկրանի ընթերցողները և ֆոկուսը աշխատում են սովորականի պես։

```tsx
import { useState } from 'react';
import { ParzToggle } from '@carparkteam/parz-ui';
import '@carparkteam/parz-ui/style.css';

const [on, setOn] = useState(true);

<ParzToggle checked={on} onChange={setOn} label="Wi-Fi" />

// չկառավարվող, առանց տեսանելի պիտակի
<ParzToggle defaultChecked ariaLabel="Մուգ թեմա" size="lg" accent="#7aa7ff" />
```

| Prop | Լռելյայն | Ինչ է անում |
|---|---|---|
| `checked` | — | Վիճակ (կառավարվող ռեժիմ) |
| `defaultChecked` | `false` | Սկզբնական վիճակ (չկառավարվող ռեժիմ) |
| `onChange` | — | `(checked: boolean) => void` — կտտոցով, ստեղնաշարով կամ քաշելով |
| `label` | — | Տեքստ կամ տարր անջատիչի կողքին |
| `labelPosition` | `'end'` | `'end'` — պիտակը աջից, `'start'` — ձախից |
| `ariaLabel` | — | Անուն էկրանի ընթերցողների համար, եթե տեսանելի `label` չկա |
| `disabled` | `false` | Անջատված, խամրած, ֆոկուս չի ստանում |
| `size` | `'md'` | `'sm'` (16 px), `'md'` (20 px), `'lg'` (28 px) կամ ուղու բարձրությունը px-ով |
| `accent` | `#6ee7a0` | Միացված ուղու գույնը |
| `trackColor` | `#2a2a30` | Անջատված ուղու գույնը։ Բաց էջում՝ օրինակ `#d9dae1` |
| `thumbColor` | `#fff` | Սահնակի գույնը |
| `draggable` | `true` | Կարելի՞ է քաշել սահնակը |
| `cooldown` | `0` | Նվազագույն դադարը փոխարկումների միջև, մվ։ Չափազանց հաճախ փորձը մերժվում է |
| `canChange` | — | `(next) => boolean` — սեփական ստուգում; `false`-ը մերժում է փոխարկումը |
| `onReject` | — | `(next) => void` — կանչվում է, երբ փորձը մերժվել է |
| `rejectColor` | `#ff5c5c` | Ուղու գույնը մերժման ժամանակ |
| `name` / `id` | — | Փոխանցվում են ներքին checkbox-ին |
| `className` / `style` | — | Արմատային `<label>`-ի վրա |

## Մերժման վիճակ

Պաշտպանություն հաճախակի միացնել/անջատելուց (օրինակ՝ սերվերին դիմող կարգավորում)՝ տվեք `cooldown`։ Եթե շատ շուտ նորից փոխարկեն, անջատիչը չի փոխվի․ մեկ վայրկյան ուղին կկարմրի, սահնակը կարճ կցնցվի, հետո ամեն ինչ հանգիստ կվերադառնա։ Նույնը՝ երբ `canChange`-ը վերադարձնում է `false`։

```tsx
<ParzToggle checked={on} onChange={setOn} label="Ծանուցումներ"
  cooldown={1500} onReject={() => toast('Չափազանց հաճախ է, սպասեք')} />
```

## CSS փոփոխականներ

Գույները կարելի է տալ նաև CSS-ով՝ անջատիչի կամ ցանկացած ծնողի վրա՝ `--pz-tg-accent`, `--pz-tg-track`, `--pz-tg-knob`, `--pz-tg-reject`։

```css
.settings { --pz-tg-accent: #ff8a3d; }
```
