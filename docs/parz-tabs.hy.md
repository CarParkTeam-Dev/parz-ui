# Parz Tabs

`ParzTabs`-ը Parz UI-ի հատվածային փոխարկիչն է։ Ընտրիչը չի ցատկում, այլ հոսում է նոր կետին․ առջևի եզրը գնում է առաջինը, պոչը հասնում է, և մի պահ ընտրիչը ձգվում է կաթիլի պես՝ ինչպես Parz Menu-ում։

- **սեղմում** — ընտրում է կետը;
- **ստեղնաշար** — Tab-ը ֆոկուսը դնում է ընտրված կետի վրա, սլաքները և Home / End-ը փոխարկում են (անհասանելիները բաց թողնելով);
- **փաթաթում** — եթե կետերը չեն տեղավորվում, անցնում են նոր տող, և ընտրիչը սահուն տեղափոխվում է այնտեղ;
- **քիչ շարժում** — `prefers-reduced-motion`-ի դեպքում ընտրիչը տեղափոխվում է առանց անիմացիայի։

Ներսում `role="radiogroup"` է `role="radio"` կոճակներով, ուստի էկրանի ընթերցիչները այն կարդում են որպես մեկ ընտրություն։

```tsx
import { useState } from 'react';
import { ParzTabs } from '@carparkteam/parz-ui';
import '@carparkteam/parz-ui/style.css';

const [tab, setTab] = useState('week');

<ParzTabs
  options={[
    { value: 'day', label: 'Օր' },
    { value: 'week', label: 'Շաբաթ' },
    { value: 'month', label: 'Ամիս' }
  ]}
  value={tab}
  onChange={setTab}
  ariaLabel="Ժամանակահատված"
/>
```

| Հատկություն | Լռելյայն | Ինչ է անում |
|---|---|---|
| `options` | — | `{ value, label?, icon?, badge?, badgeColor?, ariaLabel?, disabled? }[]` — կետերը; `badge`-ը՝ թիվ, կարճ տեքստ կամ `'dot'`, `badgePulse`՝ մեղմ զարկ |
| `value` | — | Ընտրված արժեքը (կառավարվող ռեժիմ) |
| `defaultValue` | առաջին հասանելին | Սկզբնական արժեքը (չկառավարվող ռեժիմ) |
| `onChange` | — | `(value) => void` |
| `ariaLabel` | — | Խմբի անունը էկրանի ընթերցիչների համար |
| `size` | `'md'` | `'sm'`, `'md'` կամ `'lg'` |
| `fullWidth` | `false` | Ամբողջ լայնությամբ, կետերը հավասար |
| `overflow` | `'wrap'` | Եթե կետերը չեն տեղավորվում՝ `'wrap'` — նոր տող, `'more'` — ավելորդները թաքնվում են «•••»-ում ցանկով, `'scroll'` — հորիզոնական ոլորում |
| `fadeEdges` | `true` | `'scroll'`-ի համար՝ մգացնել եզրերը, որոնց հետևում կան կետեր |
| `scrollButtons` | `false` | `'scroll'`-ի համար՝ փոքր սլաքներ եզրերին։ Դրանցով ընտրված կետն ինքնուրույն չի ոլորվում կենտրոն |
| `badgePlacement` | `'inline'` | Պիտակների տեղը՝ `'inline'` — անվան կողքին, `'corner'` — կետի վերին աջ անկյունում, առանց լայնությունը փոխելու |
| `moreIcon` | `'more'` | Մնացած կետերի կոճակի պատկերակը՝ ներկառուցված, `'ms:անուն'` կամ ձեր տարրը |
| `moreLabel` | `'More'` | «•••»-ի անունը էկրանի ընթերցիչների համար |
| `disabled` | `false` | Անջատել ամբողջ փոխարկիչը |
| `background` | `#1c1c21` | Ուղու ֆոնը |
| `pillColor` | `#fff` | Ընտրիչի գույնը |
| `activeColor` | `#000` | Ընտրված կետի տեքստը |
| `color` | `#9a9aa3` | Մյուս կետերի տեքստը |
| `id` / `className` / `style` | — | Արմատային տարրի վրա |

## Երբ կետերը չեն տեղավորվում

- **`overflow="more"`** — ինչ տեղավորվում է, մնում է շարքում, մնացածը՝ «•••»-ում։ Կոճակին չեզոք հաշվիչ է և կարմիր կետ, եթե թաքնվածների մեջ պիտակներ կան։ Սեղմեք «•••»՝ ընտրիչը հոսում է դրան և բացվում է ցանկը։
- **`overflow="scroll"`** — կետերը ոլորվում են մատով կամ անիվով, եզրերը մեղմ մգանում են (`fadeEdges={false}`՝ առանց մգացման)։ Ընտրված կետն ինքն է գալիս կենտրոն; `scrollButtons`-ով եզրերին հայտնվում են սլաքներ, իսկ ավտոոլորում չկա։ Չափը, լայնությունը կամ կետերը փոխելիս ընտրված կետը չի մնում եզրից դուրս։

```tsx
<ParzTabs options={opts} value={tab} onChange={setTab} overflow="more" />
<ParzTabs options={opts} value={tab} onChange={setTab} overflow="scroll" scrollButtons />
```

## CSS փոփոխականներ

Փոխարկիչի կամ ցանկացած ծնողի վրա՝ `--pz-tabs-bg`, `--pz-tabs-pill`, `--pz-tabs-on`, `--pz-tabs-fg`, `--pz-tabs-sh` (ընտրիչի ստվեր), `--pz-tabs-menu-bg`, `--pz-tabs-menu-fg`, `--pz-tabs-ring` (ֆոկուսի օղակ)։
